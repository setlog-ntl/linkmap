3단계 중 0단계 완료

디스플레이 설정 열기

수동 경로: 설정›시스템›디스플레이 (또는 바탕 화면 오른쪽 클릭 → 디스플레이 설정)

설정 항목별 안내

필요한 항목만 골라 여세요. 각 카드의 버튼은 그 설정 화면을 바로 엽니다. 버튼이 반응하지 않으면 카드 아래 수동 경로로 가면 됩니다.

화면 모드 · 배치 · 주 모니터

확장으로 바꾸고, 실제 놓인 위치대로 배치하고, 주로 보는 화면을 정합니다.

설정 열기

설정›시스템›디스플레이

  1. [식별]을 누르면 각 화면에 큰 숫자 1·2가 잠깐 뜹니다. 어느 모니터가 몇 번인지 확인하세요.
  2. 미리보기 옆 드롭다운에서 디스플레이 확장을 고릅니다. (「디스플레이 복제」 「1에만 표시」 「2에만 표시」도 여기)
  3. 미리보기의 1·2 상자를 실제로 놓인 위치대로 끌어다 놓고 [적용]. 위·아래 배치도 됩니다. 두 상자의 모서리 높이를 맞춰 두면 마우스가 경계에 걸리지 않습니다.
  4. 주로 보는 화면을 클릭한 뒤 여러 디스플레이를 펼쳐 이 디스플레이를 주 모니터로 만들기를 체크합니다. 시계·알림·새로 여는 창이 이 화면에 뜹니다.

모니터가 하나만 보이면 여러 디스플레이 › [감지]를 누르세요. 그래도 안 나오면 아래 「문제 해결」 첫 항목으로.

Windows 10은 이렇게
페이지 맨 위 디스플레이 다시 정렬에 [식별]·[감지]와 배치 미리보기가 있고, 아래쪽 여러 디스플레이 드롭다운에서 확장/복제를 고릅니다. 그 밑에 이 디스플레이를 주 모니터로 만들기 체크박스가 있습니다.

배율 · 해상도 · 방향

글자 크기와 선명도를 정합니다. 모니터마다 따로 설정합니다.

설정 열기

설정›시스템›디스플레이›배율 및 레이아웃

  1. 미리보기에서 바꿀 모니터를 먼저 클릭합니다. 아래 값들은 선택한 모니터에만 적용됩니다.
  2. 배율 — 「(권장)」이 붙은 값을 고릅니다. 노트북은 125~150%, 큰 모니터는 100%처럼 서로 달라도 정상입니다.
  3. 디스플레이 해상도 — 역시 「(권장)」 값. 모니터의 원래 해상도라 글자가 가장 또렷합니다.
  4. 세로로 세운 모니터는 디스플레이 방향을 세로로 바꿉니다.

「사용자 지정 배율」은 권하지 않습니다. 되돌리기 번거롭고 일부 앱이 흐려집니다. 글자만 키우고 싶으면 아래 버튼으로 접근성 › 텍스트 크기를 조절하세요 — 화면 배치는 그대로 두고 글자만 커집니다.

글자 크기만 키우기

Windows 10은 이렇게
「배율 및 레이아웃」의 텍스트, 앱 및 기타 항목의 크기 변경이 배율, 디스플레이 해상도·방향은 이름이 같습니다. 접근성 글자 크기는 「접근성 › 디스플레이 › 텍스트 크게」.

재생 빈도(주사율)

모니터가 120Hz·144Hz를 지원하는데 60Hz로 잡혀 있으면 마우스와 스크롤이 뚝뚝 끊깁니다.

설정 열기

설정›시스템›디스플레이›고급 디스플레이

  1. Windows 11에서는 디스플레이 페이지가 열립니다. 아래로 내려 「관련 설정 › 고급 디스플레이」를 누르세요. (Windows 10은 고급 페이지가 바로 열립니다)
  2. 상단 드롭다운에서 모니터를 고르고 새로 고침 빈도 선택에서 가장 높은 값을 고릅니다. (60 → 120 · 144Hz)
  3. 화면이 검게 되거나 깜빡이면 15초 안에 자동으로 되돌아갑니다. 그럴 땐 한 단계 낮은 값으로.

높은 값이 목록에 없으면 케이블·단자 한계인 경우가 대부분입니다. 예: 오래된 HDMI 케이블은 4K에서 30Hz까지만. DisplayPort 또는 HDMI 2.0 이상 케이블로 바꿔 보세요.

창 위치 기억 · 커서 이동

모니터를 뺐다 꽂아도 창이 제자리로 오게, 마우스가 경계에서 걸리지 않게.

설정 열기

설정›시스템›디스플레이›여러 디스플레이

  1. 여러 디스플레이를 펼칩니다.
  2. 모니터 연결을 기반으로 창 위치 기억 ✓ — 모니터를 뺐다 다시 꽂으면 창이 원래 화면·위치로 돌아옵니다.
  3. 모니터 연결이 끊어지면 창을 최소화합니다 ✓ — 노트북만 들고 나갔을 때 창이 보이지 않는 화면에 남지 않습니다.
  4. 디스플레이 간 커서 이동 쉽게 만들기 ✓ (22H2 이상) — 두 화면 해상도가 달라도 마우스가 모서리에 걸리지 않습니다.
Windows 10은 이렇게
이 세 옵션은 Windows 11에만 있습니다. 창이 보이지 않는 화면에 남았다면, 작업 표시줄에서 그 창을 클릭한 뒤 Win + Shift + ←/→ 로 끌어오세요.

작업 표시줄을 두 화면에

두 번째 모니터에도 작업 표시줄을 두고, 어느 화면에 어떤 앱 아이콘을 보일지 정합니다.

설정 열기

설정›개인 설정›작업 표시줄›작업 표시줄 동작

  1. 맨 아래 작업 표시줄 동작을 펼칩니다.
  2. 모든 디스플레이에 내 작업 표시줄 표시 ✓ — 두 번째 모니터에도 작업 표시줄이 생깁니다.
  3. 여러 디스플레이를 사용하는 경우 다음에서 작업 표시줄 앱을 표시합니다 — 셋 중 하나:
    • 모든 작업 표시줄 — 어느 화면에서든 모든 앱 아이콘이 보입니다.
    • 주 작업 표시줄 및 창이 열려 있는 작업 표시줄 — 주 화면엔 전부, 다른 화면엔 그 화면의 창만. 가장 무난한 선택입니다.
    • 창이 열려 있는 작업 표시줄 — 각 화면에 그 화면의 창만.
Windows 10은 이렇게
작업 표시줄 설정의 여러 디스플레이 섹션에 같은 항목이 있습니다 — 모든 디스플레이에 작업 표시줄 표시, 작업 표시줄 단추 표시 위치.

배경 화면 — 이어 붙이기 · 화면마다 다르게

파노라마 한 장을 두 화면에 걸치거나, 화면마다 다른 사진을 둡니다.

설정 열기

설정›개인 설정›배경

  1. 배경 개인 설정을 「사진」으로 두고 사진을 고릅니다.
  2. 한 장을 두 화면에 이어 붙이려면 「데스크톱 이미지에 맞게 선택」 드롭다운에서 스팬(범위)을 고릅니다. 가로로 긴 파노라마 사진이 잘 맞습니다.
  3. 화면마다 다른 사진을 두려면 「최근 이미지」의 사진을 마우스 오른쪽 클릭 → 모니터 1에 설정 / 모니터 2에 설정.

「사진 찾아보기」로 고른 사진도 최근 이미지에 들어가므로, 같은 방법으로 화면별 지정이 됩니다. 몇 번 모니터인지는 디스플레이 설정의 [식별]로 확인하세요.

Windows 10은 이렇게
같은 위치입니다. 「맞춤 선택」 드롭다운에서 스팬, 최근 이미지 오른쪽 클릭으로 모니터별 지정.

창 나누기 · 옆 모니터로 옮기기

마우스로 끌지 않아도 키 하나로 창을 붙이고 옮깁니다. 듀얼모니터에서 가장 자주 쓰는 기능입니다.

설정 열기

설정›시스템›멀티태스킹›창 스냅

  1. 창 스냅이 켜져 있는지 확인합니다. (기본은 켜짐)
  2. Win + Shift + ←/→ — 지금 보는 창을 옆 모니터로 통째로 옮깁니다. 이 키 하나만 외워도 됩니다.
  3. Win + ←/→ — 창을 화면 왼쪽/오른쪽 절반에 붙입니다. 창 제목을 화면 가장자리로 끌어도 됩니다.
  4. Win + Z — 2분할·3분할 스냅 레이아웃을 고릅니다. 창의 최대화 버튼 위에 마우스를 올려도 나옵니다.
Windows 10은 이렇게
스냅 레이아웃(Win + Z)은 없습니다. 반 화면 붙이기와 옆 모니터로 옮기기 키는 같습니다.

야간 모드 (눈 편하게)

저녁에 두 화면 모두 따뜻한 색으로 바꿔 눈부심을 줄입니다.

설정 열기

설정›시스템›디스플레이›야간 모드

  1. 야간 모드 스위치를 켭니다. 두 화면에 함께 적용되며, 「강도」 슬라이더로 조절합니다.
  2. 야간 모드 예약을 켜고 「일몰~일출」 또는 시간을 정해 두면 자동으로 켜지고 꺼집니다.

HDR 모니터라면 디스플레이 페이지의 HDR 항목에서 「HDR 사용」을 켤 수 있습니다. 모니터마다 따로 켭니다. 일반 문서 작업에는 꺼 두는 편이 색이 자연스럽습니다.

노트북 덮개를 닫아도 계속 쓰기

외부 모니터만 보고 일할 때, 노트북을 덮어도 꺼지지 않게 합니다.

설정 열기

설정›시스템›전원 및 배터리›덮개, 전원 및 절전 단추 컨트롤

  1. Windows 11 24H2 이상: 덮개, 전원 및 절전 단추 컨트롤을 펼치고 덮개를 닫으면을 「전원 연결 시」와 「배터리 사용 시」 각각 아무 작업 안 함으로 바꿉니다.
  2. 23H2 이하 · Windows 10: 아래 명령을 복사해 Win + R 에 붙여넣고 Enter → 왼쪽 덮개를 닫으면 수행되는 작업 선택 → 「아무 것도 안 함」 → 변경 내용 저장.
    powercfg.cpl제어판 전원 옵션

덮어 두면 노트북 열이 잘 빠지지 않습니다. 거치대에 세워 두고 외부 키보드·마우스를 쓰는 편이 안전합니다.

소리가 갑자기 모니터로 나갈 때

HDMI·DisplayPort로 꽂으면 소리가 모니터 스피커로 넘어가 작게 들릴 수 있습니다.

설정 열기

설정›시스템›소리›출력

  1. 출력 › 소리를 재생할 위치 선택에서 원래 쓰던 스피커나 헤드셋을 고릅니다.
  2. 영상 회의 앱은 자체 설정에 출력 장치가 따로 있으니, 거기서도 한 번 확인합니다.

작업 표시줄 오른쪽 스피커 아이콘을 누르고 슬라이더 옆 〉를 누르면 출력 장치를 바로 바꿀 수도 있습니다.

듀얼모니터 단축키

마우스로 창을 끌고 다니는 시간을 줄여 줍니다. 위 두 줄만 외워도 충분합니다.

문제 해결

증상을 누르면 해결 순서가 나옵니다. 각 항목의 버튼은 관련 설정 화면을 엽니다.

자주 겪는 8가지

위에서부터 순서대로 해 보세요. 대부분 두 번째 단계 안에서 해결됩니다.

두 번째 모니터가 아예 안 잡혀요 (신호 없음)
  1. 케이블을 양쪽 다 뺐다가 다시 꽂고, 모니터 자체 메뉴의 입력 소스(HDMI 1 · DP 등)가 꽂은 단자와 같은지 확인합니다.
  2. 디스플레이 설정 › 여러 디스플레이 › [감지].
  3. Win + Ctrl + Shift + B — 그래픽 드라이버를 다시 시작합니다.
  4. 다른 단자·다른 케이블로 바꿔 봅니다. USB-C는 영상 출력(DP Alt) 지원 단자여야 합니다 — 충전 전용 단자도 있습니다.
  5. 그래픽 드라이버를 업데이트합니다(노트북 제조사 사이트 또는 인텔·엔비디아·AMD).
디스플레이 설정 열기

글자가 흐리거나, 노트북과 모니터 글자 크기가 달라요
  1. 디스플레이 설정에서 각 모니터를 따로 선택해 배율을 「(권장)」 값으로 맞춥니다.
  2. 「사용자 지정 배율」을 썼다면 해제하고 로그아웃 → 다시 로그인합니다.
  3. 특정 앱만 흐리면 그 앱 실행 파일 오른쪽 클릭 → 속성 → 호환성 → 높은 DPI 설정 변경에서 「높은 DPI 조정 동작 재정의」를 「응용 프로그램」으로.
디스플레이 설정 열기

1번·2번이 실제 위치와 반대예요
번호는 그래픽 단자 순서라 바꿀 수 없고, 바꿀 필요도 없습니다. 미리보기의 상자를 실제 위치대로 끌어 놓고 [적용]한 뒤, 주로 보는 화면에만 「이 디스플레이를 주 모니터로 만들기」를 체크하면 끝입니다.
디스플레이 설정 열기

마우스가 엉뚱한 쪽으로 넘어가거나 경계에서 걸려요
  1. 미리보기에서 두 상자의 위아래 높이를 맞춥니다. 상자가 어긋난 만큼 경계에 「벽」이 생깁니다.
  2. 여러 디스플레이 › 디스플레이 간 커서 이동 쉽게 만들기를 체크합니다(22H2 이상).
디스플레이 설정 열기

앱이 매번 다른 모니터에 열려요
  1. 주로 보는 화면을 주 모니터로 지정합니다. 새 창은 기본적으로 주 모니터에 뜹니다.
  2. 여러 디스플레이 › 모니터 연결을 기반으로 창 위치 기억을 체크합니다.
  3. 앱은 마지막으로 닫은 위치를 기억합니다. 원하는 화면으로 옮긴 뒤 한 번 닫았다 여세요.
디스플레이 설정 열기

해상도나 주사율이 목록에 없어요
  1. 케이블·단자의 대역폭 한계가 대부분입니다. DisplayPort 또는 HDMI 2.0 이상 케이블로 바꿉니다.
  2. 도킹 스테이션·젠더를 빼고 직접 연결해 봅니다. 저가 젠더는 1080p 60Hz까지만 되는 것이 많습니다.
  3. 그래픽 드라이버를 업데이트합니다.
고급 디스플레이 열기

모니터를 꽂으면 노트북 화면이 꺼져요
화면 모드가 「두 번째 화면만」입니다. Win + P 를 눌러 확장을 고르세요. 키보드가 안 먹으면 아래 명령을 Win + R 에 붙여넣습니다.
displayswitch /extend화면 모드를 「확장」으로 즉시 전환
확장을 골랐는데 두 화면이 똑같이 나와요
  1. Win + P 를 다시 눌러 「확장」이 선택돼 있는지, 디스플레이 설정 드롭다운도 「디스플레이 확장」인지 확인합니다.
  2. 그래픽 제어판(인텔 그래픽 명령 센터 · NVIDIA 제어판 · AMD 소프트웨어)에서 복제(클론) 설정이 켜져 있으면 끕니다.
디스플레이 설정 열기

버튼이 안 열리면 — 실행창(Win+R) 명령 모음

사내 정책 등으로 버튼이 막힌 PC에서는 Win + R 을 누르고 명령을 붙여넣으세요. 메모장에 저장해 두면 언제든 씁니다.

설정 화면 바로 열기 명령

Windows 11·10 공통. 「복사」 → Win+R → 붙여넣기 → Enter.

명령여는 곳
ms-settings:display디스플레이 — 모드·배치·주 모니터·배율·해상도·방향·여러 디스플레이 옵션
ms-settings:display-advanced고급 디스플레이 — 재생 빈도 (Win11은 디스플레이 페이지로 열림 → 아래로 내려 「고급 디스플레이」)
ms-settings:taskbar작업 표시줄 — 모든 디스플레이에 표시·앱 표시 위치
ms-settings:personalization-background배경 — 스팬·모니터별 다른 배경
ms-settings:multitasking멀티태스킹 — 창 스냅
ms-settings:nightlight야간 모드
ms-settings:powersleep전원 및 배터리 — 노트북 덮개 설정 (24H2 이상)
ms-settings:sound소리 — 출력 장치
powercfg.cpl제어판 전원 옵션 — 덮개 설정 (23H2 이하 · Windows 10)
displayswitch /extend화면 모드를 「확장」으로 즉시 전환 (Win+P와 같음)
displayswitch /clone화면 모드를 「복제」로 즉시 전환

Edge·Chrome 주소창에 ms-settings:display를 직접 입력해도 열립니다.

macOS에서는

Mac은 시스템 설정 › 디스플레이 한 곳에서 거의 다 끝납니다. 아래 버튼은 macOS 13(Ventura) 이상에서 동작합니다.

macOS 설정 순서 펼치기
디스플레이 설정 열기 데스크탑 및 Dock 열기 배경화면 열기

  1. Apple 메뉴 › 시스템 설정 › 디스플레이. 연결된 모니터가 위쪽에 나란히 보입니다.
  2. 외부 모니터를 클릭하고 다음으로 사용에서 확장된 디스플레이(넓게 쓰기) / 주 디스플레이 / 미러링 중 고릅니다.
  3. 정렬…을 눌러 화면 상자를 실제 위치대로 끌어 놓습니다. 위쪽의 흰 막대(메뉴 막대)를 다른 상자로 끌면 주 디스플레이가 바뀝니다.
  4. 데스크탑 및 Dock › 맨 아래 Mission Control › 디스플레이별로 공간 분리 — 켜면 모니터마다 메뉴 막대와 전체 화면 앱이 따로 생깁니다(바꾼 뒤 로그아웃 필요).
  5. 배경화면에서 모니터별로 다른 사진을 고릅니다.

Safari에서 버튼이 반응하지 않으면 위 경로대로 직접 여세요. 창을 옆 모니터로 옮기는 단축키는 macOS에 기본으로 없습니다 — 창 제목을 끌어 옮기거나 Mission Control(Ctrl + ↑)에서 옮깁니다.
