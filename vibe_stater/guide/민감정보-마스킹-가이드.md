# 민감정보 마스킹 가이드 (녹화 전 필독)

> 문서코드: VIBE-MASK · 대상: "바이브코딩 무작정따라하기" 모든 녹화

영상은 **실제 작동하는 Claude Code 화면**을 그대로 보여주는 것이 강점이다. 단, **민감정보는 단 한 프레임도 노출되면 안 된다.** 이 가이드는 "무엇을 가리고, 무엇을 보여줄지"를 정의한다.

---

## 1. 절대 노출 금지 (가린다 🚫)

| 분류 | 예시 | 처리 |
|------|------|------|
| 시크릿/키 | `ENCRYPTION_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, 모든 `*_KEY`/`*_SECRET`/`*_TOKEN` | 값은 절대 화면에 띄우지 않음 |
| 환경설정 파일 | `.env`, `.env.local`, `wrangler.jsonc`의 비밀값 | 파일 자체를 열지 않음 |
| 인증/연결 정보 | Supabase URL·키, GitHub 토큰/OAuth, DB 연결 문자열 | 마스킹 또는 회피 |
| 개인정보(PII) | 실제 이메일·실명·전화번호·주소 | 가상값으로 대체 |
| 내부 절대경로 | `C:\Users\<실명>\...` 처럼 사용자명이 드러나는 경로 | `~/` 또는 `<project>/`로 표기 |
| 복호화된 값 | 크레덴셜/시크릿 노트의 평문 | 다루지 않음 |

## 2. 마음껏 보여주기 (교육 포인트 ✅)

- 시청자가 입력하는 **프롬프트 문장** ("나만의 홈페이지를 만들어줘")
- Claude Code의 **도구 사용 흐름** (Read / Grep / Glob / Write가 무엇을 하는지)
- **원클릭 personal-brand 템플릿의 공개 구조** (섹션·기본값·프리셋)
- 생성되는 **HTML/CSS 결과물**과 브라우저 렌더 화면
- **단계별 해설** — "지금 Claude가 왜 이 파일을 보는지"

## 3. 마스킹 표기법

| 원본 | 화면 표기 |
|------|-----------|
| 비밀값 | `••••••` 또는 `<마스킹됨>` |
| 환경변수 | 이름만: `$ENCRYPTION_KEY` (값 없이) |
| 사용자 경로 | `C:\Users\jiwon\Dev\...` → `<project>/...` 또는 `~/Dev/...` |
| 이메일 | 실제 → `hello@example.com` (example 도메인) |
| 이름 | 실제 → 템플릿 기본값 `이지원` |

## 4. 녹화 전 체크리스트

- [ ] 터미널/에디터에 `.env*` 파일 탭이 열려 있지 않다
- [ ] 환경변수 출력(`echo $...`, `env`, `printenv`) 명령을 사용하지 않는다
- [ ] Claude Code가 시크릿 관련 파일(`src/lib/crypto/`, `audit.ts`, 토큰 파일)을 읽지 않는다
- [ ] 브라우저 주소창·북마크·확장프로그램에 PII가 없다
- [ ] OS 알림(메일/메신저 미리보기)을 방해금지 모드로 차단했다
- [ ] 화면 경로에 실제 사용자명이 노출되지 않는다 (필요 시 데모 계정/경로 사용)
- [ ] 데모 데이터는 전부 가상값이다

## 5. vibe-starter 에이전트의 자동 보호

`vibe-starter` 서브에이전트는 이 정책을 **본문에 내장**하고 있어:

- 도구가 `Read`/`Grep`/`Glob`만 — 파일 쓰기·셸 실행 불가
- 참조 파일 화이트리스트 외(`.env`, crypto, audit 등)는 읽지 않음
- 출력에서 시크릿·PII를 마스킹

그래도 **최종 책임은 녹화자**에게 있다. 위 체크리스트를 매 녹화 전 확인할 것.
