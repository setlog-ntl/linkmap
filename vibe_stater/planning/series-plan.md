# 시리즈 기획서 — 바이브코딩 무작정따라하기

> 문서코드: VIBE-SERIES · 최종수정: 2026-06-27 · 상태: 기획

---

## 1. 시리즈 목표

- **무엇을**: Claude Code로 코딩하는 "바이브코딩"의 실제 작업 흐름을, **Linkmap 원클릭 배포**를 소재로 시연·교육한다.
- **왜**: "코드를 모르는 사람도 말 한마디로 결과물을 만든다"는 Linkmap 핵심 가치(원클릭 → 성장)를 직접 보여주기 위해.
- **결과**: 시청자가 영상을 보고 따라 하면, 자기만의 홈페이지(원클릭 personal-brand)를 만들고 결과를 눈으로 확인한다.

## 2. 타겟 시청자

| 우선순위 | 대상 | 특징 |
|---------|------|------|
| 1순위 | **바이브코더** | 코딩 경험 0. "만들고 싶다"는 욕구는 있으나 진입장벽을 느낌 |
| 2순위 | 입문 개발자 | Claude Code/AI 코딩 도구의 실제 사용법이 궁금한 사람 |
| 3순위 | 기획자·창작자 | 외주 없이 직접 페이지를 만들고 싶은 1인 사업자/크리에이터 |

## 3. 핵심 메시지

1. 바이브코딩 = **"무엇을 원하는지 말하면" Claude Code가 만들어준다.**
2. 좋은 결과는 **좋은 프롬프트**에서 나온다 (구체적으로 말하기).
3. Linkmap 원클릭은 그 결과를 **실제 내 홈페이지**로 만들어준다.

## 4. 1편당 포맷

- **러닝타임**: 5~8분 (입문자가 끝까지 보기 좋은 길이)
- **구성 5단계** (= vibe-starter 진행 단계와 동일):
  1. **도입** (30초) — 오늘 만들 것 미리보기 ("이런 홈페이지를 말 한마디로 만듭니다")
  2. **프롬프트** (1분) — 시청자가 입력할 한 마디 + 왜 그렇게 말하는지
  3. **실행** (2~3분) — Claude Code가 작업하는 화면 (도구 흐름·해설 자막)
  4. **결과** (1~2분) — 브라우저로 결과물 띄우고 둘러보기
  5. **정리** (30초) — 오늘의 교육 포인트 1개 + 다음 화 예고

## 5. 회차 로드맵

| 화 | 제목 | 프롬프트 예시 | 결과물 | 상태 |
|----|------|--------------|--------|------|
| **1화** | 나만의 홈페이지 만들기 | "나만의 홈페이지를 만들어줘" | personal-brand 기본 페이지(HTML) 브라우저 표시 | ✅ 자산 준비완료 |
| 2화 | 디자인 테마 바꾸기 | "테마를 미드나잇으로 바꿔줘" | 프리셋 전환(creator→midnight) 비교 | 🔜 후보 |
| 3화 | 섹션 추가하기 | "갤러리 섹션을 켜줘" | gallery 모듈 활성화 결과 | 🔜 후보 |
| 4화 | 내용 채우기 | "내 소개랑 가치관을 이렇게 바꿔줘" | About/Values 커스터마이즈 | 🔜 후보 |
| 5화 | 진짜로 배포하기 | "이 홈페이지를 인터넷에 올려줘" | 원클릭 GitHub Pages 배포(개념·주의사항) | 🔜 후보 |

> 1~4화는 로컬 standalone HTML로 안전하게 시연. 5화(실배포)는 계정·토큰이 개입하므로 마스킹 가이드를 특히 엄격히 적용.

## 6. 녹화 가이드 (요약)

- **화면 구성**: 좌측 Claude Code 터미널 / 우측 브라우저(결과물). 자막으로 "지금 무슨 일이 일어나는지" 설명.
- **민감정보**: 녹화 전 [`../guide/민감정보-마스킹-가이드.md`](../guide/민감정보-마스킹-가이드.md) 체크리스트 필수 확인.
- **속도**: 실행 대기 구간은 2~4배속 + 핵심 컷만 정속. 도구 호출(Read/Grep)은 "Claude가 파일을 살펴보는 중" 자막.
- **캡처 포인트**: ① 프롬프트 입력 순간 ② 도구 흐름 ③ 결과 HTML 첫 렌더 ④ 스크롤하며 섹션 둘러보기.

## 7. vibe-starter 에이전트 사용법

- 진행 도우미로 `vibe-starter` 서브에이전트를 호출 (트리거: "바이브코딩 교육 시작", "나만의 홈페이지 만들어줘").
- 에이전트는 **읽기전용** — 실제 코드/구조를 읽어 해설하고, HTML 산출물을 텍스트로 제시한다.
- **HTML 저장·브라우저 실행은 메인 세션**이 수행:
  - 저장 위치: `vibe_stater/demo/output/`
  - 열기: `start vibe_stater\demo\output\<파일>.html`
- 상세 동작/설치: [`../agent/vibe-starter.reference.md`](../agent/vibe-starter.reference.md)
