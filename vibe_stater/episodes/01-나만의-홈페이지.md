# 1화 대본 — "나만의 홈페이지를 만들어줘"

> 시리즈: 바이브코딩 무작정따라하기 · 러닝타임 목표 6~7분 · 결과물: `demo/personal-brand-sample.html`

---

## 🎯 이 화의 목표

코딩을 전혀 몰라도, **"나만의 홈페이지를 만들어줘"** 한 마디로 진짜 홈페이지(원클릭 personal-brand 기본 페이지)가 브라우저에 뜨는 것을 보여준다.

**오늘의 교육 포인트 (한 가지)**: 바이브코딩은 *"무엇을 원하는지 말하는 것"* 에서 시작한다.

---

## 🎬 컷 구성 (5단계)

### ① 도입 (0:00–0:30) — 결과 먼저 보여주기
- 화면: 완성된 홈페이지(`demo/personal-brand-sample.html`)를 브라우저에서 위→아래로 스크롤.
- 내레이션: "오늘은 이 홈페이지를, 코드 한 줄 안 쓰고 말 한마디로 만들어 볼게요."
- 자막: `Hero → About → Values → Highlights → Contact`

### ② 프롬프트 (0:30–1:30) — 무엇을 말할까
- 화면: Claude Code 프롬프트 입력창.
- **입력 프롬프트**:
  ```
  나만의 홈페이지를 만들어줘
  ```
- 내레이션: "이게 전부예요. 그런데 한 가지 팁 — **구체적으로 말할수록** 결과가 좋아져요."
- 자막(프롬프트 팁): "원하는 느낌·이름·소개를 덧붙이면 더 내 것처럼 나옵니다. 예) '크리에이터용으로, 따뜻한 색감으로 만들어줘'"

### ③ 실행 (1:30–4:00) — Claude Code가 일하는 과정
- 화면: `vibe-starter` 서브에이전트가 실행되며 도구를 사용하는 흐름.
- 자막으로 각 단계 해설:
  | Claude의 행동 | 시청자용 자막 |
  |---------------|---------------|
  | `Glob`으로 템플릿 파일 탐색 | "어떤 홈페이지 재료가 있는지 찾는 중" |
  | `Read`로 personal-brand 구조 읽기 | "기본 홈페이지가 어떻게 생겼는지 살펴보는 중" |
  | 섹션·기본값 정리 | "내 홈페이지에 들어갈 칸들을 정리하는 중" |
  | HTML 산출물 생성 | "실제로 보이는 페이지로 조립하는 중" |
- ⚠️ 마스킹: 이 구간에서 `.env`·키·내부경로가 절대 보이지 않도록(가이드 체크리스트).

### ④ 결과 (4:00–6:00) — 브라우저로 띄우기
- 화면(메인 세션 작업): HTML을 `demo/output/`에 저장 후 브라우저로 열기.
  ```powershell
  start vibe_stater\demo\output\my-homepage.html
  ```
  (사전 준비된 `demo/personal-brand-sample.html`을 그대로 써도 동일)
- 둘러보기 포인트:
  - **Hero**: 이름 "이지원 / Jiwon Lee" + 한줄소개, 따뜻한 그라데이션(creator 테마)
  - **About**: 자기소개 글
  - **Values**: 진정성 · 일관성 · 호기심 카드(마우스 올리면 살짝 떠오르는 효과)
  - **Highlights**: 84,000+ / 120+ / 312주 숫자
  - **Contact**: 이메일 + 소셜 버튼
- 내레이션: "보세요, 진짜 홈페이지가 떴죠? 이게 Linkmap 원클릭의 기본 페이지예요."

### ⑤ 정리 (6:00–6:30) — 마무리 + 예고
- 내레이션: "오늘 기억할 건 딱 하나 — **원하는 걸 말하면 만들어진다.**"
- 다음 화 예고: "다음엔 이 홈페이지의 **색 테마**를 말 한마디로 바꿔볼게요."
