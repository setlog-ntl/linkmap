"나만의 홈페이지를 만들어줘"

⏱ 러닝타임 6~7분 🎯 코딩 경험 0 대상 📦 결과물: personal-brand-sample.html
코딩을 전혀 몰라도, "나만의 홈페이지를 만들어줘" 한 마디로 진짜 홈페이지(원클릭 personal-brand 기본 페이지)가 브라우저에 뜨는 것을 보여줍니다.
오늘의 교육 포인트 (한 가지): 바이브코딩은 "무엇을 원하는지 말하는 것"에서 시작한다.
①
도입 — 결과 먼저 보여주기
0:00–0:30
화면
완성된 홈페이지(demo/personal-brand-sample.html)를 브라우저에서 위 → 아래로 스크롤.
내레이션
"오늘은 이 홈페이지를, 코드 한 줄 안 쓰고 말 한마디로 만들어 볼게요."
자막
Hero → About → Values → Highlights → Contact
②
프롬프트 — 무엇을 말할까
0:30–1:30
화면
Claude Code 프롬프트 입력창.
입력 프롬프트
나만의 홈페이지를 만들어줘
내레이션
"이게 전부예요. 그런데 한 가지 팁 — 구체적으로 말할수록 결과가 좋아져요."
자막 (프롬프트 팁)
원하는 느낌·이름·소개를 덧붙이면 더 내 것처럼 나옵니다. 예) '크리에이터용으로, 따뜻한 색감으로 만들어줘'
③
실행 — Claude Code가 일하는 과정
1:30–4:00
화면
vibe-starter 서브에이전트가 실행되며 도구를 사용하는 흐름. 자막으로 각 단계 해설:
Claude의 행동시청자용 자막
Glob"어떤 홈페이지 재료가 있는지 찾는 중"
Read"기본 홈페이지가 어떻게 생겼는지 살펴보는 중"
섹션·기본값 정리"내 홈페이지에 들어갈 칸들을 정리하는 중"
HTML 생성"실제로 보이는 페이지로 조립하는 중"
이 구간에서 .env·키·내부경로가 절대 보이지 않도록 (마스킹 가이드 체크리스트 준수).

4:00–6:00
