# LINKMAP 서비스 기능 리뷰 QA 리포트

- **검수일시**: 2026년 4월 16일
- **대상 URL**: https://linkmap.biz
- **검수 범위**: 메인 랜딩 페이지, 가격 페이지, 쇼케이스, 블로그, 기능 요청, 404 페이지
- **환경**: Windows / Chrome / Desktop (1568px 해상도)

---

## 검수 요약

전체 6개 주요 페이지를 탐색하여 기능 및 UI 상태를 점검했습니다.
정상 동작 페이지: 가격(/pricing), 블로그(/blog), 기능 요청(/feedback), 쇼케이스(/showcase)
문제 발견 페이지: 메인(/), 404 에러 페이지, 서비스 탐색 내비 링크

## 발견된 문제점 (5건)

### 문제 1: 메인 페이지 "핵심 기능" 섹션 콘텐츠 미렌더링 (심각도: HIGH)

**위치**: 메인 페이지 > "THE WORKSPACE / 핵심 기능" 섹션

**현상**: "핵심 기능" 제목과 "프로젝트 설정에 필요한 모든 것을 한 곳에서"라는 부제목만 표시되고, 그 아래 하위 콘텐츠(기능 카드, 설명 등)가 전혀 렌더링되지 않습니다. 약 700px 이상의 거대한 빈 공간이 발생하며, 사용자에게 "페이지가 깨졌다"는 인상을 줍니다.

**예상 원인**:
- JavaScript 기반 애니메이션/인터랙션 컴포넌트의 로딩 실패
- Scroll-reveal 또는 Intersection Observer 기반 lazy-load가 트리거되지 않음
- SSR/SSG 과정에서 클라이언트 전용 컴포넌트가 hydration에 실패

**영향**: 서비스의 핵심 가치 제안(환경변수 관리, 서비스맵, AI 기능 등)이 사용자에게 전달되지 않아 전환율에 직접적 영향

**권장 수정**:
- `interactive-demo.tsx`, `feature-card.tsx`, `scroll-reveal.tsx` 등 랜딩 컴포넌트 hydration 확인
- fallback UI 또는 로딩 스켈레톤 추가
- 서버 콘솔 및 브라우저 콘솔 에러 로그 확인 필요

---

### 문제 2: 404 에러 페이지 글로벌 네비게이션 바 누락 (심각도: MEDIUM)

**위치**: 존재하지 않는 URL 접근 시 (예: /nonexistent-page-test)

**현상**: 404 에러 페이지에 상단 글로벌 네비게이션 바(헤더)가 완전히 누락되어 있습니다. 페이지에는 "홈으로"와 "대시보드" 버튼만 존재하며, 사용자가 다른 섹션(가격, 블로그, 쇼케이스 등)으로 직접 이동할 수 없습니다. 또한 푸터도 없어 페이지가 "고립된" 상태입니다.

**영향**: 
- 사용자가 잘못된 URL에 도달했을 때 사이트 내 탐색 경로가 제한됨
- 브랜드 일관성 저하 (다른 페이지들은 모두 헤더/네비를 포함)
- SEO 크롤러가 404 페이지에서 사이트 구조를 파악할 수 없음

**권장 수정**:
- `not-found.tsx` 또는 404 페이지 레이아웃에 글로벌 Header 컴포넌트 추가
- Footer 컴포넌트도 포함하여 일관된 레이아웃 유지
- 검색 기능이나 인기 페이지 링크 추가 고려

---

### 문제 3: "서비스 탐색" 내비게이션 링크 동작 이상 (심각도: MEDIUM)

**위치**: 상단 네비게이션 바 > "서비스 탐색" 메뉴

**현상**: 네비게이션 바에 "서비스 탐색"이라는 독립 메뉴 항목이 존재하지만, 클릭 시 별도의 탐색 페이지로 이동하지 않고 메인 홈페이지(/)로 리다이렉트됩니다. 네비게이션에서 해당 메뉴가 볼드(강조) 처리되지만, 실제로는 홈페이지와 동일한 콘텐츠를 보여줍니다.

**영향**:
- 사용자 혼란 유발 (별도 페이지를 기대하지만 홈으로 돌아감)
- 네비게이션 구조의 신뢰성 저하
- "서비스 탐색" 기능이 미완성 상태로 노출

**권장 수정**:
- 별도의 `/explore` 또는 `/services` 페이지를 구현하거나
- 해당 메뉴를 홈페이지 내 특정 섹션으로 스크롤하는 앵커 링크로 변경하거나
- 기능이 준비될 때까지 네비게이션에서 임시 제거

---

### 문제 4: 메인 페이지 템플릿 카드 썸네일 이미지 미표시 (심각도: MEDIUM)

**위치**: 메인 페이지 > 템플릿 소개 섹션 (나만의 홈페이지, 디지털 명함, 개발자 홈, 링크카드, 모바일 초대장)

**현상**: 각 템플릿 카드 상단의 프리뷰/썸네일 영역이 빈 다크 사각형(placeholder)으로만 표시됩니다. 텍스트 설명은 정상 렌더링되지만, 시각적 프리뷰가 없어 사용자가 템플릿의 실제 모습을 확인할 수 없습니다. 또한 "개발자 홈" 카드의 설명 텍스트("나를 보여주는 개발자 홈...")가 카드 너비를 넘어 잘리는 현상이 있습니다.

**영향**:
- 템플릿 선택 시 시각적 참고 자료 부재로 사용자 의사결정 어려움
- 서비스의 완성도가 낮아 보이는 인상
- "개발자 홈" 카드 텍스트 잘림으로 정보 전달 불완전

**권장 수정**:
- 각 템플릿의 실제 스크린샷 또는 목업 이미지를 추가
- 이미지 로딩 실패 시 의미 있는 placeholder(예: 템플릿 이름 표시) 사용
- "개발자 홈" 카드 텍스트에 `text-overflow: ellipsis` 또는 카드 너비 조정

---

### 문제 5: 사용자 후기 섹션 레이아웃 불균형 (심각도: LOW)

**위치**: 메인 페이지 > 사용자 후기/리뷰 섹션

**현상**: 사용자 후기 섹션에 "김민수 / 프론트엔드 개발자" 1건의 리뷰 카드만 좌측에 표시되고, 화면의 우측 절반 이상이 완전히 비어 있습니다. 리뷰가 1건뿐인 경우, 카드가 중앙 정렬되거나 섹션 전체 레이아웃이 이에 맞게 조정되어야 합니다.

**영향**:
- 시각적 불균형으로 "콘텐츠 부족"이라는 부정적 인상
- 서비스 신뢰도를 높이기 위한 소셜 프루프 역할 미흡
- 1개 후기가 모든 후기처럼 보여 오히려 역효과 가능

**권장 수정**:
- 후기가 소수일 경우 중앙 정렬 레이아웃으로 변경
- 추가 후기 확보 후 캐러셀/슬라이드 형태로 표시
- 후기가 부족하면 해당 섹션을 임시 비활성화하는 것도 고려

## 종합 평가

전반적인 서비스 구조와 디자인은 잘 갖추어져 있으나, 메인 랜딩 페이지에 사용자의 첫인상을 좌우하는 핵심 섹션(기능 소개, 템플릿 프리뷰)에서 렌더링 문제가 집중되어 있어 긴급 수정이 필요합니다. 특히 "핵심 기능" 섹션 미렌더링은 서비스의 가치 전달에 직접적 영향을 미치므로 최우선 수정 대상입니다.

**우선순위 정리**:
1. [HIGH] 핵심 기능 섹션 콘텐츠 렌더링 수정
2. [MEDIUM] 템플릿 카드 썸네일 이미지 추가
3. [MEDIUM] 404 페이지 네비게이션 바 추가
4. [MEDIUM] "서비스 탐색" 내비 링크 수정
5. [LOW] 후기 섹션 레이아웃 조정
