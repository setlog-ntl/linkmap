# Small Biz 템플릿

> **Slug**: `small-biz`
> **대상**: 동네 가게, 카페, 베이커리, 음식점, 소규모 매장
> **설명**: 메뉴, 영업시간, 위치, SNS가 포함된 소상공인 홍보 페이지

---

## 1. 모듈 구성 (6개)

| # | 모듈 ID | 이름 | 아이콘 | 필수 | 기본 활성 | 설명 |
|---|---------|------|--------|------|-----------|------|
| 1 | `hero` | 가게 정보 | Store | O | O | 가게 이름, 한줄 소개, 전화번호 |
| 2 | `menu` | 메뉴 | UtensilsCrossed | X | O | 카테고리별 메뉴 + 가격 |
| 3 | `hours` | 영업시간 | Clock | X | O | 요일별 영업시간 (오늘 강조) |
| 4 | `location` | 위치 | MapPin | X | O | 주소 + 카카오맵 연동 |
| 5 | `gallery` | 갤러리 | Image | X | **X** | 가게/메뉴 사진 (가로 스크롤) |
| 6 | `sns` | SNS | Share2 | X | O | 인스타그램, 네이버 블로그, 카카오톡 채널 |

**기본 순서**: hero → menu → hours → location → gallery → sns

**특징**: 한국 소상공인에 완전 특화된 유일한 템플릿 (카카오맵, 네이버 블로그, 카카오톡 채널)

## 4. 현재 기능 요약

### 구현 완료
- [x] 가게 정보 (이름 + 소개 + 전화번호 + 색상 + 폰트)
- [x] 메뉴 카드 (카테고리별 그룹핑 + 가격 + 이모지)
- [x] 영업시간 표 (오늘 자동 강조 + 휴무일 표시)
- [x] 카카오맵 임베드 연동
- [x] 갤러리 가로 스크롤 캐러셀
- [x] 한국 특화 SNS (인스타, 네이버 블로그, 카카오톡 채널)
- [x] 한국어/영문 이중 언어 지원
- [x] 4가지 프리셋 (업종별 최적화)

### 특수 기능
- **메뉴 최대 30개**: 실제 식당/카페 메뉴를 충분히 수용
- **카테고리 자동 그룹핑**: 같은 category 값끼리 묶어서 표시
- **오늘 강조**: JavaScript Date API로 현재 요일 자동 감지
- **전화번호 → 클릭 투 콜**: `tel:` 링크로 모바일에서 바로 전화
- **카카오맵 임베드**: kakaoMapId로 지도 자동 삽입

## 5. 고도화 포인트 (기획 참고)

### P1 — 단기 개선
- [ ] **메뉴 이미지**: 각 메뉴에 사진 URL 필드 추가
- [ ] **메뉴 뱃지**: "BEST", "NEW", "매진" 등 상태 뱃지
- [ ] **영업시간 예외**: 특별 영업일/임시 휴무 공지
- [ ] **네이버 지도 옵션**: 카카오맵 대신 네이버 지도 선택 가능
- [ ] **가게 로고/대표 이미지**: Hero에 이미지 업로드 필드 추가
- [ ] **배달 링크**: 배달의민족, 요기요 주문 링크

### P2 — 중기 기능
- [ ] **온라인 예약**: 날짜/시간/인원수 예약 폼 모듈
- [ ] **쿠폰/이벤트**: 할인 쿠폰, 이벤트 배너 모듈
- [ ] **리뷰 연동**: 네이버 플레이스, Google 리뷰 자동 가져오기
- [ ] **다국어 메뉴판**: 영어/일본어/중국어 메뉴 자동 생성 (관광지 대응)
- [ ] **메뉴 QR 코드**: 테이블에 놓을 QR → 메뉴 페이지 직접 연결

### P3 — 장기 확장
- [ ] **POS 연동**: 메뉴 가격/재고 자동 동기화
- [ ] **매출 대시보드**: 방문수, 전화클릭수, 지도클릭수 통계
- [ ] **계절 메뉴 자동 전환**: 날짜 기반 메뉴 자동 활성/비활성
- [ ] **포장 주문**: 간단한 온라인 주문 시스템
- [ ] **Google Business Profile 연동**: 영업시간, 리뷰 양방향 동기화
- [ ] **Instagram 피드 연동**: 최신 게시물 자동 갤러리 표시
