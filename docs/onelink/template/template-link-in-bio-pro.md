# Link-in-Bio Pro 템플릿

> **Slug**: `link-in-bio-pro`
> **대상**: 소셜 미디어 인플루언서, 크리에이터
> **설명**: 커스텀 테마가 적용된 심미적 링크 모음 페이지 (Linktree 대체)

---

## 1. 모듈 구성 (4개)

| # | 모듈 ID | 이름 | 아이콘 | 필수 | 기본 활성 | 설명 |
|---|---------|------|--------|------|-----------|------|
| 1 | `profile` | 프로필 | User | O | O | 프로필 사진, 이름, 한줄 소개 |
| 2 | `links` | 링크 목록 | Heart | O | O | 클릭 가능한 링크 카드 목록 |
| 3 | `socials` | 소셜 바 | Mail | X | O | 하단 소셜 미디어 아이콘 바 |
| 4 | `theme` | 테마 | Sparkles | X | O | 색상 테마 + 배경 스타일 + 카드 스타일 |

**기본 순서**: profile → links → socials → theme

**특징**: 6개 템플릿 중 가장 적은 모듈 수 (4개). 심플하고 집중된 구조.

---

## 2. 모듈별 필드 상세

### 2.1 Profile (프로필) — 필수

| 필드 | 타입 | 기본값 | 유효성 검사 | 비고 |
|------|------|--------|-------------|------|
| `name` | text | `""` | required, maxLength: 50 | |
| `nameEn` | text | `""` | — | |
| `bio` | textarea | `""` | maxLength: 200 | 짧은 소개 |
| `bioEn` | textarea | `""` | — | |
| `avatarUrl` | url | `""` | — | 프로필 이미지 URL |

**영향 파일**: `config.ts`

### 2.2 Links (링크 목록) — 필수

| 필드 | 타입 | 기본값 | 비고 |
|------|------|--------|------|
| `items` | array | 2개 기본 항목 | **최대 15개** (가장 많은 maxItems) |

**배열 아이템 스키마**:
| 서브필드 | 타입 | 유효성 검사 | 비고 |
|----------|------|-------------|------|
| `title` | text | required | 링크 제목 |
| `url` | url | required | 링크 URL |
| `emoji` | text | maxLength: 4 | 아이콘 이모지 (선택) |

**기본 아이템**: "내 블로그", "YouTube 채널"

**영향 파일**: `config.ts`

### 2.3 Socials (소셜 바)

| 필드 | 타입 | 기본값 | 비고 |
|------|------|--------|------|
| `items` | array | Instagram, YouTube | 최대 8개 |

**소셜 플랫폼 옵션 (7개)**: YouTube, Instagram, X(Twitter), GitHub, LinkedIn, TikTok, **Facebook**

**차이점**: 다른 템플릿 대비 Facebook이 추가됨

**영향 파일**: `config.ts`

### 2.4 Theme (테마)

| 필드 | 타입 | 기본값 | 비고 |
|------|------|--------|------|
| `primaryColor` | color | `#6366f1` | 메인 색상 (인디고) |
| `bgStyle` | select | `gradient` | 배경 스타일 선택 |
| `cardStyle` | select | `rounded` | 카드 모서리 스타일 |

**배경 스타일 옵션**:
| 값 | 설명 |
|----|------|
| `gradient` | 그래디언트 배경 |
| `solid` | 단색 배경 |
| `mesh` | 메쉬 그래디언트 배경 |

**카드 스타일 옵션**:
| 값 | 설명 |
|----|------|
| `rounded` | 둥근 모서리 |
| `pill` | 알약형 (크게 둥근) |
| `square` | 직각 모서리 |

**영향 파일**: `config.ts`, `globals.css`

## 4. 현재 기능 요약

### 구현 완료
- [x] 프로필 (아바타 + 이름 + 바이오)
- [x] 최대 15개 링크 카드 (이모지 아이콘 지원)
- [x] 7개 소셜 플랫폼 아이콘 바
- [x] 테마 커스터마이징 (메인 색상 + 배경 스타일 + 카드 스타일)
- [x] 한국어/영문 이중 언어 지원
- [x] 2가지 프리셋
- [x] 모듈 on/off + 드래그 순서 변경

### 특수 기능
- **필수 모듈 2개**: profile과 links가 모두 필수 (끌 수 없음)
- **테마 모듈**: 다른 템플릿에는 없는 bgStyle(배경), cardStyle(카드 모양) 커스텀
- **기본값 비어있음**: name, bio 등 기본값이 빈 문자열 → 사용자 입력 필수

## 5. 고도화 포인트 (기획 참고)

### P1 — 단기 개선
- [ ] **테마 프리셋**: 10개 사전 정의 색상 조합 (gradient, neon, minimal, pastel, dark, ocean, sunset, forest, candy, monochrome) — 스키마에 정의되어 있지만 UI 미구현
- [ ] **링크 클릭 통계**: 각 링크별 클릭 수 추적
- [ ] **링크 아이콘**: 이모지 대신 URL 파비콘 자동 추출 또는 아이콘 피커
- [ ] **링크 그룹핑**: 카테고리별 링크 분류 (e.g., "콘텐츠", "쇼핑", "SNS")
- [ ] **프로필 이미지 업로드**: URL 직접 입력 → 파일 업로드 + 크롭

### P2 — 중기 기능
- [ ] **애니메이션 링크 카드**: hover 시 bounce, scale 등 효과 선택
- [ ] **배경 이미지/비디오**: 단색/그래디언트 외에 이미지 or 비디오 배경
- [ ] **링크 스케줄링**: 특정 시간대에만 표시되는 링크 (프로모션용)
- [ ] **QR 코드 생성**: 링크 페이지 전체 QR 코드
- [ ] **커스텀 CSS**: 고급 사용자를 위한 CSS 오버라이드

### P3 — 장기 확장
- [ ] **스토어 연동**: 쇼핑 링크에 가격/상품 미리보기 카드
- [ ] **뉴스레터 구독**: 이메일 수집 폼 모듈 추가
- [ ] **스플래시 애니메이션**: 페이지 진입 시 인트로 효과
- [ ] **멀티 페이지**: 링크가 많을 때 탭 or 스와이프 페이지 분리
- [ ] **방문자 분석 대시보드**: 방문 수, 체류 시간, 유입 경로
