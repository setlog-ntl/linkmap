# Digital Namecard 템플릿

> **Slug**: `digital-namecard`
> **대상**: 비즈니스 전문가, 네트워커, 영업직
> **설명**: QR 코드와 vCard 다운로드가 포함된 인터랙티브 디지털 명함

---

## 1. 모듈 구성 (4개)

| # | 모듈 ID | 이름 | 아이콘 | 필수 | 기본 활성 | 설명 |
|---|---------|------|--------|------|-----------|------|
| 1 | `profile` | 프로필 | User | O | O | 이름, 직함, 회사, 프로필 이미지 |
| 2 | `contact` | 연락처 | Mail | O | O | 이메일, 전화, 주소, 웹사이트 + QR + vCard |
| 3 | `socials` | 소셜 링크 | Share2 | X | **X** | 소셜 미디어 아이콘 링크 |
| 4 | `theme` | 테마 | Palette | X | O | 명함 상단 바 및 강조 색상 |

**기본 순서**: profile → contact → socials → theme

**특징**: 필수 모듈 2개 (profile, contact). socials가 기본 비활성 상태.

## 2. 모듈별 필드 상세

| 필드 | 타입 | 기본값 | 유효성 검사 | 비고 |
|------|------|--------|-------------|------|

**차이점**: `title`(직함)과 `company`(회사) 필드가 있는 유일한 프로필 모듈

### 2.2 Contact (연락처) — 필수

| 필드 | 타입 | 기본값 | 유효성 검사 | 비고 |
|------|------|--------|-------------|------|

**영향 파일**: `config.ts`

**핵심 차별점**: 이 연락처 모듈에 QR 코드 생성 + vCard(.vcf) 다운로드 + 명함 인쇄 기능이 내장

### 2.3 Socials (소셜 링크) — 기본 비활성

| 필드 | 타입 | 기본값 | 비고 |
|------|------|--------|------|
| `items` | array | `[]` | 최대 8개 |

**소셜 플랫폼 옵션 (7개)**: LinkedIn, X(Twitter), Instagram, GitHub, Facebook, YouTube, TikTok

**차이점**: LinkedIn이 기본 선택값 (비즈니스 특화), 기본 아이템이 빈 배열

**영향 파일**: `config.ts`

### 2.4 Theme (테마)

| 필드 | 타입 | 기본값 | 비고 |
|------|------|--------|------|

**차이점**: Link-in-Bio Pro의 테마(3필드)와 달리 `accentColor` 단일 필드만 — 명함의 상단 바와 강조 요소에 적용

## 4. 현재 기능 요약

### 구현 완료
- [x] 프로필 (이름 + 직함 + 회사 + 아바타)
- [x] 연락처 (이메일 + 전화 + 주소 + 웹사이트)
- [x] QR 코드 자동 생성 (vCard 포맷)
- [x] "연락처 저장" 버튼 → vCard(.vcf) 파일 다운로드
- [x] 명함 인쇄 지원 (90mm x 55mm 규격)
- [x] 7개 소셜 플랫폼 지원
- [x] 강조 색상 커스터마이징
- [x] 한국어/영문 이중 언어 지원
- [x] 2가지 프리셋

### 특수 기능
- **QR 코드**: 프로필+연락처 정보를 vCard 포맷으로 인코딩
- **vCard 다운로드**: iOS/Android 연락처 앱에 바로 추가 가능
- **인쇄 모드**: CSS @media print로 명함 규격(90x55mm) 출력
- **비즈니스 특화**: LinkedIn 기본값, 전화번호+주소+회사 필드

## 5. 고도화 포인트 (기획 참고)

### P1 — 단기 개선
- [ ] **QR 코드 커스터마이징**: 로고 삽입, 색상 변경, 사이즈 조절
- [ ] **명함 레이아웃 변형**: 가로형/세로형/미니멀/클래식 등 레이아웃 프리셋
- [ ] **프로필 이미지 업로드**: URL → 파일 업로드 + 원형 크롭
- [ ] **NFC 태그 연동**: NFC 태그에 명함 URL 쓰기 가이드
- [ ] **다중 연락처**: 개인/업무 연락처 분리 (토글 전환)

### P2 — 중기 기능
- [ ] **명함 교환**: 상대방도 명함 URL 입력 → 양방향 저장
- [ ] **방문 알림**: 명함이 열릴 때 이메일/푸시 알림
- [ ] **브랜딩 워터마크**: 회사 로고 워터마크 옵션
- [ ] **애니메이션**: 카드 플립, 슬라이드 인 등 진입 효과
- [ ] **다크/라이트 모드**: 자동 감지 + 수동 토글

### P3 — 장기 확장
- [ ] **CRM 연동**: 명함 스캔 시 HubSpot/Salesforce 자동 등록
- [ ] **명함첩**: 교환한 명함들을 모아보는 대시보드
- [ ] **분석**: 명함 조회수, QR 스캔 횟수, vCard 다운로드 수
- [ ] **AI 자기소개**: 직함+회사 기반 자기소개문 자동 생성
- [ ] **팀 명함**: 회사 단위 일괄 생성 + 브랜딩 통일
