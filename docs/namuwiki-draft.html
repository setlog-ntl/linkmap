1. 개요

Linkmap은 외부 서비스 간 연결을 시각화하고 API 키 및 환경변수를 안전하게 관리하는 웹 플랫폼이다. 코딩 경험이 없는 초보자(바이브코더)부터 여러 SaaS를 조합하는 스타트업 개발자까지, 프로젝트에 사용되는 서비스들의 구조를 한눈에 파악하고 관리할 수 있도록 돕는다.

"원클릭 배포로 시작하고, 배우면서 만들고, 만들면서 관리된다"라는 슬로건 아래, 단순 배포 도구를 넘어 학습과 실전이 하나로 연결되는 성장형 플랫폼을 지향한다.

3. 핵심 컨셉: 2층 퍼널 구조

Linkmap은 사용자의 성장 단계에 따라 자연스럽게 기능이 확장되는 2층 퍼널 구조를 채택하고 있다.

1

1층: 진입 (원클릭 배포)

코딩 경험이 없는 사용자가 템플릿을 선택해 첫 웹페이지를 만들고 GitHub Pages로 실제 배포한다.

"와, 나도 사이트가 생겼다!"

→
2

2층: 성장 (가이드 + 서비스 관리)

가이드를 따라 서비스를 연결하면 서비스맵에 노드가 추가되고, 환경변수가 채워지고, Health Check가 활성화된다.

학습과 실전이 분리되지 않는 단일 흐름

핵심 원리: 사용자는 "관리하러" 오는 게 아니라 "배우다 보니" 관리가 되어 있는 경험을 얻는다. 서비스맵, 환경변수 암호화, Health Check, 감사 로그는 별도 도구가 아니라 가이드를 따라 배우는 과정에서 자연스럽게 채워지는 인프라이다.

4. 주요 기능

서비스맵 시각화

프로젝트에 연결된 모든 서비스를 React Flow 기반 인터랙티브 다이어그램으로 표시한다. 서비스 간 의존 관계, 데이터 흐름을 시각적으로 파악할 수 있다.

React Flow 드래그 & 드롭 PCB 메타포
환경변수 암호화 관리

API 키, 시크릿 등 민감한 환경변수를 AES-256-GCM으로 암호화하여 중앙 관리한다. .env.local 매핑을 지원하며, 복호화된 값은 절대 로그에 남지 않는다.

AES-256-GCM IV 개별 생성
서비스 카탈로그

90개 이상의 외부 서비스(Supabase, Stripe, OpenAI 등)에 대한 상세 정보를 제공한다. 필수 환경변수, 가격, 난이도, 대안 서비스 등을 한눈에 비교할 수 있다.

90+ 서비스 가격 비교
원클릭 배포

8종 이상의 템플릿(링크카드, 디지털 명함, 개발자 포트폴리오, 프리랜서 페이지, 소상공인 홍보 등)을 선택해 GitHub Pages로 즉시 배포한다.

GitHub Pages 8+ 템플릿
Health Check (상태 모니터링)

연결된 서비스들의 동작 상태를 자동으로 모니터링한다. 장애 발생 시 빠르게 인지할 수 있도록 대시보드에 표시된다.

실시간 모니터링
감사 로그 (Audit Log)

환경변수 생성/수정/삭제/복호화, 프로젝트 변경 등 모든 민감 작업을 기록한다. 사용자 ID, 액션, 리소스, IP 주소 등이 포함된다.

보안 감사 JSONB 상세
비용 추적

프로젝트에 연결된 서비스별 월 비용을 자동으로 계산하고 추적한다. 무료 티어 정보와 유료 전환 시점을 함께 제공한다.

월 비용 계산
연결 관리

서비스 간 의존 관계(연결)를 PCB(인쇄 회로 기판) 메타포의 시각적 인터페이스로 관리한다. 드래그로 연결을 생성/해제할 수 있다.

PCB 메타포 드래그 연결

부가 기능

  • GitHub 멀티 계정 연동 (OAuth)
  • MCP 서버 제공 (Claude Code / Cursor 연동)

아키텍처 특징

  • Server Components 기본, 인터랙티브 UI만 Client Components 사용
  • Row-Level Security(RLS)로 데이터 격리 (모든 테이블)
  • API 5단계 패턴: 인증 → Zod 검증 → 소유권 확인 → 비즈니스 로직 → 감사 로그

  • DB 마이그레이션 72개 이상, 테이블 35개 이상

8. 보안

데이터 암호화
  • 환경변수: AES-256-GCM 암호화
  • 값마다 고유 16바이트 IV 생성
  • Auth Tag로 데이터 무결성 보장
  • 저장 형식: iv:authTag:encryptedData
  • 복호화된 값 로깅/API 응답 포함 금지
인증 & 인가
  • Supabase Auth (이메일/비밀번호 + OAuth)
  • 쿠키 기반 세션 관리
  • RLS로 사용자별 데이터 격리
  • API + DB 이중 소유권 검증
  • API 토큰: SHA-256 해시만 저장
인프라 보안
  • Cloudflare Rate Limiting (앱 코드 외부)
  • HSTS, X-Frame-Options: DENY
  • X-Content-Type-Options: nosniff
  • Permissions-Policy (카메라/마이크/위치 차단)
  • poweredByHeader 비활성화
감사 & 규정 준수
  • 모든 민감 작업 감사 로그 기록
  • 사용자 ID, 액션, 리소스, IP 추적
  • 환경별 키 분리 (dev/staging/prod)
  • 키 로테이션 절차 문서화
  • .env 파일 커밋 차단 (.gitignore)

11. 경쟁 서비스 비교

비교 대상 차이점
Lovable / Replit Lovable과 Replit은 AI 기반 풀스택 빌더로, 코드 생성부터 배포까지 깊은 기능을 제공한다. Linkmap은 코드 생성보다는 간단한 배포 + 학습 경로 + 서비스 연결 관리에 초점을 맞춘다.
Doppler / HashiCorp Vault 전문 시크릿/환경변수 관리 도구. 강력하지만 학습 곡선이 높다. Linkmap은 관리 도구가 아닌, 배우면서 자연스럽게 관리되는 경험을 추구한다.
Vercel / Netlify 배포 플랫폼 자체. Linkmap은 이들과 경쟁이 아니라 보완 관계로, Vercel 등의 배포 위에서 서비스 간 연결과 환경변수를 통합 관리한다.
Linktree 링크 모음 서비스. Linkmap의 원클릭 배포 템플릿(Link Card) 중 하나와 유사하지만, Linkmap은 그 이후 개발자 성장 경로(서비스 관리)까지 연결된다.
Linkmap의 핵심 차별점: 진입(배포) → 학습(가이드) → 관리(인프라)가 끊기지 않는 단일 퍼널. 다른 서비스들은 이 세 단계 중 하나에만 특화되어 있다.
