# 블로그 마크다운 작성 가이드

> `posts.ts`의 `content` 필드에 작성하는 마크다운 규칙을 정리합니다.

---

## 1. 콜아웃 (Blockquote)

### 5종 문법

```markdown
> **KEY:** 글의 핵심 요약. 첫 번째에 배치하여 글의 메시지를 즉시 전달.

> **TIP:** 실용적 조언, 팁, 추천. Linkmap 기능 연결에 적합.

> **WARNING:** 주의사항, 위험, 실수. 보안/비용 관련 경고에 사용.

> **INFO:** 부가 정보, 통계, 배경 설명. Linkmap 수치/카탈로그 언급에 적합.

> **TRY:** CTA (Call-to-Action). 글 하단에 배치하여 행동 유도. Linkmap 가입/시작 링크.
```

### 배분 규칙

| 규칙 | 내용 |
|------|------|
| 총 개수 | 포스트당 **4~6개** |
| KEY | **반드시 1개**, 글 최상단에 배치 |
| TRY | **반드시 1개**, 글 하단에 배치 |
| TIP / WARNING / INFO | 본문 흐름에 맞게 2~4개 배치 |
| 연속 금지 | 콜아웃 2개 연속 배치 금지 (사이에 본문 필요) |
| 비율 | 콜아웃 텍스트 ≤ 전체 본문의 30% |

### 렌더링 스타일

| 타입 | 왼쪽 border | 배경 | 라벨 |
|------|-----------|------|------|
| KEY | brand-blue | blue-50 | KEY |
| TIP | brand-green | green-50 | TIP |
| WARNING | amber-500 | amber-50 | WARNING |
| INFO | purple-500 | purple-50 | INFO |
| TRY | brand-blue | blue→green gradient | TRY IT |

## 2. 본문 구조

### 제목 규칙

```markdown
## H2 — 메인 섹션 제목 (4~7개)
### H3 — 하위 섹션 (필요 시)
```

| 규칙 | 내용 |
|------|------|
| H1 금지 | `# H1` 사용 금지 (title 필드가 H1 역할) |
| H2 개수 | 4~7개 (TOC 자동 생성 기준: 3개 이상) |
| H2 스타일 | 명사형 종결, 간결하게 (예: "바이브 코딩의 실전 워크플로") |
| H4+ 금지 | H4 이하 제목 사용 금지 (깊이 제한) |

### 본문 흐름 패턴

```
> **KEY:** 핵심 요약

## 도입 — 문제 정의

본문 텍스트...

> **INFO/WARNING:** 부가 정보

## 본론 1
## 본론 2
...

---  ← 구분선 (CTA 카드 삽입 기준)

## 실전 적용 / 추천

> **TIP:** 실용 조언

## 마무리

> **TRY:** CTA

---  ← 구분선

*교차 링크 문장 (이탤릭)*
```

## 3. 코드 블록

### 일반 코드

````markdown
```bash
# 커맨드 예시
git log --all --full-history -- .env
```
````

### ASCII 다이어그램 (언어 태그 없음)

````markdown
```
내 앱 ────├── Supabase (DB + Auth)
          ├── Vercel (배포)
          └── OpenAI (AI 기능)
```
````

### 이스케이프 규칙

content 필드는 **template literal** (백틱 3개)이므로:

| 대상 | 이스케이프 |
|------|----------|
| 백틱 (\`) | `\\\`` |
| 코드블록 (```) | `\\\`\\\`\\\`` |
| 달러 기호 ($) | `\\$` (template literal 내 변수 방지) |
| GitHub Actions secrets | `\\${{ secrets.XXX }}` |

## 4. 테이블

```markdown
| 구분 | 항목 A | 항목 B |
|------|--------|--------|
| 행 1 | 값 | 값 |
| 행 2 | **강조** | 값 |
```

- 반응형 자동 처리 (overflow-x-auto)
- `**강조**` 사용 가능
- 복잡한 테이블은 4열 이하로 제한

---

## 5. 체크리스트

```markdown
- [x] 완료 항목 (취소선 + 체크 아이콘)
- [ ] 미완료 항목 (빈 체크박스)
```

- 글 하단 "지금 바로 할 수 있는 체크리스트" 섹션에 적합
- 완료 1~2개 + 미완료 3~5개 패턴

## 6. 링크 정책

### 링크 유형별 렌더링

| 유형 | 경로 패턴 | 스타일 | 아이콘 |
|------|----------|--------|--------|
| 가이드 | `/guides/*` | 녹색 | ChevronRight |
| 서비스 | `/services/*` | 보라색 | ChevronRight |
| 블로그 | `/blog/*` | brand-blue | ChevronRight |
| 기타 내부 | `/signup`, `/pricing` 등 | brand-blue | ChevronRight |
| 외부 | `https://...` | brand-blue + underline | ExternalLink |

### 밀도 제한 (포스트당)

| 링크 유형 | 허용 범위 | 예시 |
|----------|----------|------|
| 외부 링크 | 2~3개 | Cursor, GitHub, Supabase 공식 |
| 가이드 링크 `/guides/*` | 1~2개 | 관련 가이드 교차 링크 |
| 블로그 링크 `/blog/*` | 1~2개 | 관련 포스트 교차 링크 |
| Linkmap 링크 | 3~5개 | linkmap.biz, /services, /signup, /pricing |
| **합계** | **8~12개** | 과도하면 가독성 저하 |

### 링크 작성 규칙

```markdown
<!-- 가이드 링크 -->
[환경변수 완전 정복 가이드](/guides/env)

<!-- 블로그 링크 -->
[바이브 코딩이란 무엇인가](/blog/what-is-vibe-coding)

<!-- Linkmap 링크 (도메인 포함) -->
[Linkmap](https://www.linkmap.biz)
[서비스 카탈로그](https://www.linkmap.biz/services)
[무료로 시작하기](https://www.linkmap.biz/signup)

<!-- 외부 링크 -->
[Cursor](https://cursor.com)
```

## 7. CTA 배치 규칙

### 구분선 (`---`)으로 CTA 삽입

`blog-post.tsx`는 `---`를 기준으로 콘텐츠를 분할하여 **중간에 CTA 카드를 자동 삽입**합니다.

| 규칙 | 내용 |
|------|------|
| 구분선 최소 개수 | **2개 이상** (중간 CTA 삽입 보장) |
| 구분선 위치 | 본문 50~70% 지점 + 글 마무리 직전 |
| 구분선 앞뒤 | 빈 줄 필수 (`\n---\n`) |

### CTA 구조

```
중간 CTA (자동): 구분선 기준으로 자동 삽입 → CtaCard 컴포넌트
하단 CTA (수동): > **TRY:** 콜아웃으로 직접 작성
마무리 교차 링크: *이탤릭으로 관련 가이드/블로그 안내*
```

## 8. 금지 사항

| 금지 | 이유 |
|------|------|
| `# H1` 사용 | title 필드가 H1 역할 |
| `![이미지](url)` | 이미지 미지원 (public 폴더 미사용) |
| HTML 태그 | ReactMarkdown이 HTML 무시 |
| 콜아웃 2개 연속 | 가독성 저하 |
| 접두사 없는 blockquote | 일반 인용문은 사용 가능하나, 콜아웃 접두사 권장 |
| H4 이하 제목 | 구조 복잡도 제한 |
| 인라인 이미지 | 미지원 |

## 9. 마무리 교차 링크 패턴

글 마지막에 이탤릭으로 관련 콘텐츠를 안내합니다:

```markdown
*환경변수 기초는 [환경변수 완전 정복 가이드](/guides/env), .env 위험성은 [.env 파일은 왜 위험한가](/blog/why-dotenv-is-dangerous)를 참고하세요.*
```

| 규칙 | 내용 |
|------|------|
| 형식 | 이탤릭 (`*...*`) 1~2문장 |
| 내용 | 가이드 1개 + 블로그 1개 교차 링크 |
| 위치 | 마지막 `---` 바로 아래 |
