2알고리즘 — BFS 역방향 그래프 순회
연결 방향 정의
source_service → target_service: "source가 target을 사용"

B가 장애 시 → B를 사용하는 모든 서비스가 영향받음
예시 그래프:
A → B (A uses B)
C → B (C uses B)
D → C (D uses C)
B 장애 시 영향:
A → depth 1 (High)
C → depth 1 (High)
D → depth 2 (Medium, C 경유)
리스크 레벨 기준
🔴 High (직접 영향)
depth = 1. 장애 서비스를 직접 사용하는 서비스.
🟡 Medium (간접 영향)
depth = 2. 영향받는 서비스에 의존하는 서비스.
⚪ Low (미미한 영향)
depth ≥ 3. 멀리 떨어진 간접 의존.
