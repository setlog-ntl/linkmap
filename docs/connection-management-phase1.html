문제
GET 쿼리 파라미터 ?environment= 값을 검증 없이
PostgREST .or() 문자열에 직접 삽입.
// 취약 코드 (수정 전) query = query.or(`environment.eq.${environment},...`) // 악의적 입력 예시 ?environment=prod,environment.is.null
수정
허용된 값 목록(화이트리스트)으로 먼저 검증 후 사용.
// 수정 후 const VALID_ENVS = ['development', 'staging', 'production'] const environment = VALID_ENVS.includes(envParam) ? envParam : null // null이면 .or() 호출 자체를 건너뜀
