1 전체 IA (Information Architecture)

인증 가이드는 허브 페이지를 중심으로 각 프로바이더별 서브 가이드로 분기하는 구조입니다.

/guides — 가이드 목록
  /guides/auth — 인증 가이드 허브 HUB
    ├─ HeroSection + TwoLayerDiagram
    ├─ AuthBasicsSection — 두 가지 인증 레이어 설명
    ├─ GuideLinkCards — 구글/카카오 상세 가이드 카드
    ├─ AppLoginSection + ServiceAuthSection
    ├─ ComparisonTable + GlossarySection
    └─ FaqSection

  /guides/auth/google — 구글 로그인 설정 SUB
    ├─ 7 Steps + 12 Screenshots (어노테이션 포함)
    ├─ OAuth Flow Diagram
    └─ Troubleshooting Accordion

  /guides/auth/kakao — 카카오 로그인 설정 SUB
    ├─ 6 Steps + 10 Screenshots (어노테이션 포함)
    ├─ 접근 방식 비교 (OIDC vs 직접 구현)
    └─ Troubleshooting Accordion

허브 페이지 구성

2 구글 로그인 가이드 — 7단계 스크린샷 목업

각 단계별 스크린샷이 실제 가이드에 어떻게 표시되는지 시각적으로 보여줍니다. 빨간 원은 클릭 위치, 파란 테두리는 입력 필드, 노란 영역은 확인/복사 대상입니다.

1

Google Cloud 프로젝트 생성

Google Cloud Console에서 새 프로젝트를 생성합니다

어디서?
console.cloud.google.com
무엇을?
새 프로젝트 만들기
왜?
OAuth 정보가 프로젝트 안에 생성됨
console.cloud.google.com
click 01-project-dropdown.png — 프로젝트 선택 드롭다운 클릭
console.cloud.google.com/projectcreate
input click 01-new-project-form.png — 이름 입력 후 "만들기" 클릭
2

OAuth 동의 화면 설정

External 선택 → 앱 이름, 지원 이메일 입력 → email, profile, openid 스코프 추가

console.cloud.google.com/apis/credentials/consent
click highlight 02-consent-menu.png + 02-external-select.png — External 선택
.../consent — 범위(Scopes) 추가
highlight 02-scope-add.png — email, profile, openid 스코프 확인
3

OAuth 클라이언트 ID 생성

사용자 인증 정보 만들기 > OAuth 클라이언트 ID > 웹 애플리케이션

.../apis/credentials
click input 03-credentials.png — 인증정보 만들기 + 리디렉션 URI 입력
4

Client ID / Secret 복사

생성 완료 모달에서 두 값을 복사합니다

OAuth 클라이언트 생성됨
highlight click 04-created-modal.png — ID와 Secret 각각 복사
5

Supabase Google Provider 활성화

Supabase Dashboard > Authentication > Providers > Google

supabase.com/dashboard/.../auth/providers
click input providers-list.png + google-settings.png — Provider 설정
6

URL Configuration 설정

Site URL 입력 + Redirect URLs에 앱 도메인 추가

supabase.com/dashboard/.../auth/url-configuration
input url-config.png — Site URL과 Redirect URLs 설정
7

동작 확인

npm run dev → 로그인 페이지 → Google 로그인 클릭 → 대시보드 도착

localhost:3000/login → accounts.google.com → /dashboard
flow 07-login-flow.png — 전체 로그인 플로우 확인

3 카카오 로그인 가이드 — 6단계 스크린샷 목업

카카오 개발자 콘솔에서 앱 생성부터 Supabase OIDC 연동까지의 각 단계 목업입니다.

1

카카오 앱 생성

내 애플리케이션 → 추가하기 → REST API 키 복사

developers.kakao.com/console/app
click highlight 01-console + 01-add-app + 01-rest-api-key — 앱 생성 후 키 복사
2

카카오 로그인 활성화 + OpenID Connect

활성화 설정 ON + OpenID Connect 활성화

developers.kakao.com/console/app/.../login
click 02-login-menu + 02-activation + 02-oidc — 로그인 활성화
3

Redirect URI + 동의항목

콜백 URL 등록 + 이메일 필수 동의 설정

developers.kakao.com/.../redirect
input click 03-redirect-uri-input.png — 콜백 URL 등록
developers.kakao.com/.../consent
highlight 04-email-required.png — 이메일 필수 동의 (비즈 앱 전환 필요)
5

Client Secret + Supabase OIDC 등록

보안 메뉴에서 시크릿 생성 → Supabase Custom OIDC Provider 설정

developers.kakao.com/.../security
click highlight 05-security-code-gen.png — 시크릿 생성 후 복사
supabase.com/dashboard/.../auth/providers — Custom OIDC
input custom-oidc-form.png — OIDC Provider 정보 입력

4 어노테이션 컴포넌트 디자인

스크린샷 위에 오버레이되는 3가지 어노테이션 타입. 사용자에게 어떤 동작이 필요한지 직관적으로 전달합니다.

Click

"이 버튼을 클릭하세요"
빨간 펄스 원형 + 번호 뱃지

Input

"이 필드에 값을 입력하세요"
파란 테두리 박스 + 라벨

Highlight

"이 값을 확인/복사하세요"
노란 반투명 배경

5 Playwright 캡처 계획 + 제약사항

캡처 대상 요약

대상캡처 수접근 방식제약
Google Cloud Console8장수동 로그인 후 Playwright 캡처2FA, 보안 챌린지
Supabase Dashboard4장수동 로그인 후 Playwright 캡처프로젝트 필요
카카오 개발자 콘솔10장수동 로그인 후 Playwright 캡처비즈 앱 전환 필요
Linkmap 로그인 플로우4장로컬 dev 서버 자동 캡처없음
!
UI 변경 위험: GCP, Supabase, 카카오 콘솔의 UI는 수시로 변경됩니다. 스크린샷 촬영일을 기록하고, 분기별 갱신 리뷰를 권장합니다.
