# Linkmap 서비스 소개

> **한 문장 정의**: 외부 서비스 연결을 시각화하고, 환경변수를 안전하게 관리하며, 원클릭으로 웹사이트를 배포하는 DevTools 플랫폼

**URL**: [https://www.linkmap.biz](https://www.linkmap.biz)
**문서 작성일**: 2026-03-22

## 3. 주요 기능

### 3.1 서비스맵 (Service Map)

React Flow 기반 인터랙티브 다이어그램으로 프로젝트 아키텍처를 시각화합니다.

- **3가지 뷰**: 한눈에 보기 / 맵 보기 / 의존성 보기
- **Zone 그룹핑**: Frontend · Backend · DevTools · ETC 4개 영역
- **실시간 상태**: 연결됨(초록) · 진행 중(노랑) · 오류(주황) · 시작 전(회색)
- **편집 모드**: 노드 드래그, Zone 이동(포함 노드 같이 이동), 연결 생성/삭제
- **포커스 모드**: 클릭한 서비스 + 1-hop 이웃만 강조
- **공유**: 읽기 전용 공개 링크 생성 (share_token)

### 3.2 환경변수 관리

- **AES-256-GCM 암호화**: 64자 hex 키로 모든 값 암호화 저장
- **환경별 분리**: development / staging / production
- **서비스별 템플릿**: 카탈로그 서비스의 필수/선택 환경변수 자동 안내
- **.env 다운로드**: `.env.local` 형식으로 한번에 다운로드
- **GitHub Secrets 동기화**: 연결된 저장소에 자동 업데이트
- **충돌 감지**: 환경별 변수 불일치 경고
- **복원 기능**: 삭제된 변수 복구

## 8. 보안

### 암호화
- **알고리즘**: AES-256-GCM
- **대상**: 환경변수, OAuth 토큰, API 키, Webhook 시크릿
- **키 길이**: 64자 hex (256비트)

### 접근 제어
- **Row-Level Security (RLS)**: 모든 테이블에 적용
- **API 5단계 검증**: 인증 → 입력 검증 → 소유권 확인 → 비즈니스 로직 → 감사 로그
- **복호화된 값**: 로깅 및 API 응답 포함 절대 금지

### 감사 로그
- 환경변수 CRUD, 서비스 계정 변경, 팀원 관리, API 토큰 관리, 프로젝트 삭제
- user_id, action, entity_type, entity_id, metadata, timestamp 기록
