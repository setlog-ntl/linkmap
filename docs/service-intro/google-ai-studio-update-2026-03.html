1. Google AI Studio란?

Google AI Studio(aistudio.google.com)는 Google의 Gemini 모델 패밀리에 접근하기 위한 웹 기반 통합 개발 플랫폼입니다.


2025~2026년 사이 단순한 "프롬프트 플레이그라운드"에서 풀스택 앱 빌더로 진화했습니다:

  • - Build Mode (바이브 코딩): 자연어로 React 앱을 생성·배포
  • - Full-stack Runtime: 서버 사이드 로직, 시크릿 관리, npm 패키지 지원
  • - API 키 발급: 결제 수단 없이 무료 티어 즉시 사용 가능
  • - 프로토타이핑: 모델 테스트, 프롬프트 엔지니어링, 코드 생성
  • - Prepay/Postpay 빌링: 2026년 3월부터 AI Studio 내 직접 결제 플랜 지원

6. 빠른 시작 (Quick Start)

Step 1. SDK 설치

npm install @google/genai

Step 2. API 키 설정

# .env.local
GEMINI_API_KEY=AIza...

API 키는 Google AI Studio에서 무료 발급

Step 3. 기본 사용 (TypeScript)

import { GoogleGenAI } from '@google/genai';

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

// 텍스트 생성 (Gemini 2.5 Flash 추천)
const response = await ai.models.generateContent({
  model: 'gemini-2.5-flash',
  contents: '양자 컴퓨팅을 쉽게 설명해줘.',
});
console.log(response.text);

// 멀티모달: 이미지 + 텍스트
const vision = await ai.models.generateContent({
  model: 'gemini-2.5-flash',
  contents: [
    { inlineData: { mimeType: 'image/jpeg', data: base64ImageData } },
    '이 이미지에서 보이는 것을 설명해줘.',
  ],
});

// 채팅 세션 (상태 유지)
const chat = ai.chats.create({ model: 'gemini-2.5-flash' });
const reply = await chat.sendMessage({ message: '2+2는?' });
console.log(reply.text);

Step 4. 스트리밍 (Next.js API Route)

import { GoogleGenAI } from '@google/genai';
import { NextRequest } from 'next/server';

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY! });

export async function POST(req: NextRequest) {
  const { message } = await req.json();

  const stream = await ai.models.generateContentStream({
    model: 'gemini-2.5-flash',
    contents: message,
  });

  const encoder = new TextEncoder();
  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        const text = chunk.text ?? '';
        controller.enqueue(encoder.encode(`data: ${JSON.stringify({ text })}\n\n`));
      }
      controller.enqueue(encoder.encode('data: [DONE]\n\n'));
      controller.close();
    },
  });

  return new Response(readable, {
    headers: { 'Content-Type': 'text/event-stream' },
  });
}

7. 주의사항 & 팁

장점 (Pros)

  • 결제 수단 없이 사용 가능한 넉넉한 무료 플랜
  • 텍스트·이미지·오디오·비디오·PDF 네이티브 멀티모달
  • 최대 1M 토큰 초장문 컨텍스트 (2.5 Pro)
  • 이미지/비디오/음악 생성까지 단일 API로 통합
  • OpenAI 호환 API로 기존 코드 마이그레이션 용이
  • Batch API로 대량 처리 시 50% 비용 절감
  • Build Mode로 코딩 없이 앱 프로토타이핑 가능

단점 (Cons)

  • 높은 토큰 사용량 시 종량제 비용이 빠르게 증가
  • API 인터페이스가 자주 변경 — 모델 lifecycle 주의 필요
  • 무료 티어 데이터가 모델 개선에 사용될 수 있음
  • Gemini 3 시리즈는 아직 Preview — 프로덕션 사용 시 주의
  • 일부 지역에서 기능 제한 (성인 콘텐츠 생성 등)

Common Pitfalls

문제해결
구버전 @google/generative-ai 사용 @google/genai으로 마이그레이션. import를 GoogleGenAI로 변경
폐기된 gemini-2.0-flash 모델 사용 2026.06.01 종료 예정. gemini-2.5-flash 또는 gemini-3-flash-preview로 전환
브라우저에서 직접 API 호출 API 키 노출 위험. 프로덕션에서는 반드시 서버 프록시 사용
무료 티어 속도 제한 초과 요청 큐잉/캐싱 구현. 프로덕션은 Pay-as-you-go 전환
Grounding 비용 미인지 Google Search grounding은 별도 과금 ($14/1,000쿼리). 필요한 요청에만 활성화
