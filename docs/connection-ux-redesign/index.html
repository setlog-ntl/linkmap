01 현재 상태 분석

현재 연결 생성 흐름 (5단계)

발견성 (Discoverability)

연결 핸들이 완전히 투명하여 호버 전까지 존재를 알 수 없음. 우클릭 메뉴 진입점은 초보자가 발견하기 어려운 패턴.

인지 부하 (Cognitive Load)

5단계 프로세스 중 "연결 시작 모드"라는 별도 상태가 생기며, 사용자는 현재 무엇을 해야 하는지 혼란을 겪음.

흐름 단절 (Flow Interruption)

타입 선택 모달이 전체 화면을 가리며 캔버스 컨텍스트를 잃음. 연결 위치와 타입 선택이 공간적으로 분리됨.

실수 복구 (Error Recovery)

Undo/Redo 부재로 잘못된 연결 생성 시 수동 삭제 필요. 다중 선택 불가로 일괄 작업 불가.

02 벤치마킹: Excalidraw

Excalidraw에서 차용할 5가지 핵심 인터랙션 패턴과 Linkmap에의 적용 방안.

1

핸들 호버 가시화 (Handle Affordance)

Excalidraw: 요소 호버 시 4방향에 연결 포인트 fade-in. 드래그 가능함을 즉각 인지.

Linkmap 적용

IC 칩 핀 형태의 핸들로 변환. 호버 시 핀이 외부로 확장되며 "드래그하여 연결" 툴팁 표시. 핀 색상으로 입/출력 방향 구분.

2

드래그 투 커넥트 (Drag-to-Connect)

Excalidraw: 핸들에서 드래그 시작 → 대상 요소 위에서 릴리스 → 즉시 연결 생성. 중간 단계 없음.

Linkmap 적용

핀에서 드래그 시작 시 PCB 트레이스 프리뷰 라인 표시. 유효 타겟 노드 하이라이트. 드롭 시 인라인 팝오버로 타입 선택 (기본값 자동 추론).

3

스마트 스냅 & 정렬 (Smart Snap)

Excalidraw: 드래그 중 가까운 요소에 자동 스냅. 정렬 가이드라인 표시.

Linkmap 적용

연결선이 대상 핀에 자기(magnet) 스냅. PCB 직각 경로(orthogonal routing) 자동 생성. 기존 트레이스와 겹치지 않도록 자동 우회.

4

인라인 편집 (Inline Editing)

Excalidraw: 요소 더블클릭 시 모달 없이 즉석 텍스트 편집. 컨텍스트 유지.

Linkmap 적용

엣지 더블클릭 → 라벨/타입/메모 인라인 편집. 노드 더블클릭 → 이름/설명 즉석 편집. ESC로 취소, Enter로 확인.

5

Undo/Redo 히스토리 (Command History)

Excalidraw: Ctrl+Z/Y로 모든 액션 되돌리기. 실수 비용 제로.

Linkmap 적용

연결 생성/삭제/타입 변경/위치 이동을 모두 히스토리 스택에 기록. Ctrl+Z/Y + 툴바 버튼 양쪽 지원. 히스토리 50개 유지.

04 UX 개선안: 드래그 연결

Before → After 비교

항목 현재 개선 후
핸들 가시성 투명 (발견 불가) 호버 시 IC 핀 핸들 fade-in + 툴팁
연결 시작 우클릭 → 메뉴 → "연결 시작" 핸들에서 드래그 시작 (1 액션)
타입 선택 모달 다이얼로그 (전체 차단) 인라인 팝오버 (컨텍스트 유지)
실수 복구 수동 삭제만 가능 Ctrl+Z/Y 히스토리 스택
다중 선택 불가 Shift+클릭 / 영역 선택
엣지 편집 별도 패널 열기 더블클릭 인라인 편집

개선된 연결 생성 흐름 (2단계)

인터랙션 시나리오 (상세)

1

호버 → 핸들 가시화

서비스 노드에 마우스를 올리면 상하좌우에 IC 핀 형태의 연결 핸들이 0.15s fade-in. 핀 색상: 출력(green), 입력(blue). 커서가 grab으로 변경.

2

드래그 시작 → 트레이스 프리뷰

핀에서 마우스 다운+드래그 시 직각 경로의 PCB 트레이스 프리뷰 라인 표시. 점선 + 네온 글로우. 유효하지 않은 영역에서는 빨간색으로 변경.

3

타겟 스냅 → 하이라이트

드래그 커서가 유효 타겟 노드 반경 40px 이내 진입 시 자기 스냅. 타겟 노드에 글로우 링 + 입력 핀 확대. 연결 가능 여부 즉시 피드백.

4

드롭 → 인라인 팝오버

타겟 위에서 마우스 업 시 드롭 지점 근처에 인라인 팝오버 표시. 서비스 조합 기반 타입 자동 추론 + 신뢰도 표시. 원클릭 확인 또는 타입 변경.

5

확인 → 연결 생성 + 애니메이션

팝오버 확인 시 트레이스가 점선에서 실선으로 전환. 생성 완료 효과: 트레이스를 따라 데이터 패킷(rect) 1회 흐름. 히스토리 스택에 push. sonner 토스트 "연결 생성됨".

05 비주얼 차별화: PCB 메타포

"살아있는 회로 기판" 메타포로 기능적 정보 시각화와 브랜드 차별화를 동시에 달성합니다.

PCB 메타포 인터랙티브 프리뷰 (다크 모드)

IC 칩 노드

카테고리별 핀 수/형태 차등. 서비스 크기에 비례. LED 상태 인디케이터 (green/amber/red). 실크스크린 라벨.

PCB 트레이스 엣지

직각 경로(orthogonal routing). 교차점에 Via Hole 마커. 데이터 패킷(rect) 파티클 애니메이션. 타입별 색상.

회로 기판 캔버스

다크: PCB 도트 그리드 + Via Hole 배경. 라이트: Blueprint 스타일 격자. 줌에 따라 그리드 밀도 변화.

Copper Layer 존

서비스 그룹을 해칭 패턴 영역으로 시각화. 실크스크린 스타일 라벨 (monospace). 접기/펼치기 지원.

네온 글로우

다크모드 전용 엣지/노드 글로우 강화. 활성 연결은 밝은 글로우, 비활성은 감쇠. 호버 시 글로우 증폭.

데이터 패킷 파티클

트레이스 위를 이동하는 작은 직사각형 파티클. 연결 활성 상태를 직관적으로 표현. 속도로 트래픽 양 시각화.

06 정보 밀도 관리: LOD 시스템

줌 레벨에 따라 표시되는 디테일을 자동 조절하여, 30+ 서비스 규모에서도 가독성을 유지합니다.

Overview

< 0.5x
  • • 노드 → 색상 원형 (아이콘/라벨 숨김)
  • • 엣지 → 번들링된 두꺼운 선
  • • 존(Zone) 라벨만 표시
  • • 트래픽 히트맵 오버레이

Standard

0.5–1.2x
  • • 노드 → IC 칩 + 이름 + LED
  • • 엣지 → PCB 트레이스 + 라벨
  • • 핀 → 호버 시 표시
  • • 패킷 파티클 애니메이션

Detail

> 1.2x
  • • 핀 라벨 상시 표시 (API/AUTH/DB...)
  • • 환경변수 프리뷰 패널
  • • 실크스크린 + 상세 메타데이터
  • • 연결 메모/설명 인라인 표시
