Linkmap 서비스 아이콘 & 기능 버튼 툴팁 적용 기획

2026-03-22 DESIGN SPEC

3-Tier 툴팁 계층 구조

정보 밀도에 따라 3단계로 분류하여, 각 상황에 맞는 수준의 정보를 제공합니다.

1

Simple Label

아이콘 버튼에 1줄 행동 동사
delay 400ms

2

Service Label

서비스 아이콘에 이름+카테고리
delay 300ms

3

Rich Info

서비스맵 노드에 상태/진행률
delay 300ms

TIER 1

Simple Label - 아이콘 버튼 툴팁

아이콘만 있는 버튼에 간결한 1줄 라벨을 제공합니다. 단축키도 함께 표시하여 파워유저 전환을 유도합니다.

BEFORE - 현재

설명 없는 아이콘 버튼

아이콘만 보이고 기능을 알 수 없음

? 뭐하는 버튼이지?
AFTER - 적용 후

호버 시 라벨 + 단축키 표시

각 버튼 위에 마우스를 올려보세요

복사Ctrl+C
값 표시
수정E
삭제Del
설정
// 적용 코드 (IconTooltip 래퍼)
import { IconTooltip } from '@/components/ui/icon-tooltip';

// Before: 설명 없는 아이콘 버튼
<Button variant="ghost" size="icon"><Copy /></Button>

// After: 1줄 래퍼로 툴팁 적용
<IconTooltip label="복사" shortcut="Ctrl+C">
  <Button variant="ghost" size="icon"><Copy /></Button>
</IconTooltip>

Delay 전략 - 업계 벤치마크 기반

GitHub Primer 3단계 체계를 참고하여, Linkmap에 최적화된 지연 시간을 설정합니다.

skipDelayDuration 동작 원리
1. 첫 번째 노드 호버 → 300ms 후 툴팁 표시
2. 마우스를 다른 노드로 이동 → 즉시 (200ms 이내) 표시
3. 서비스맵에서 노드를 연속 탐색할 때 체감 속도 대폭 향상
sideOffset 변경
현재: 0px (트리거 요소에 밀착)
변경: 4px (트리거를 가리지 않는 간격)
NNGroup 권장: 4~6px 간격으로 트리거 요소 가시성 확보
