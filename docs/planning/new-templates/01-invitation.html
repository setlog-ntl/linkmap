1. 타겟 사용자 & 시나리오

1차 타겟

결혼 준비 커플, 돌잔치/백일 준비 부모, 생일 파티 기획자

2차 타겟

바이브코더가 지인 행사를 위해 빠르게 만들어주는 케이스, 소규모 모임(동창회, 동호회) 주최자

사용 시나리오

"다음 달 결혼식인데 모바일 청첩장을 직접 만들고 싶어요. 바른청첩장은 월 구독이 부담되고..."
"아이 돌잔치 초대장을 카카오톡으로 공유하고 싶어요. 디자인은 프리셋으로 골라서 바로!"
"회사 송년회 초대장을 만들어야 하는데, URL 하나면 되니까 이걸로 하자"

2. 시장성 & 수요 분석

지표수치/설명
한국 연간 결혼 건수약 19만건 (모바일 청첩장 비율 90%+)
돌잔치/백일/생일연 수백만 건의 초대장 수요
기존 서비스 가격바른청첩장 월 4,900원~, 빈티지레터 건당 2만원~
Linkmap 차별점무료 + GitHub Pages 영구 호스팅 + 완전 커스터마이징
계절성봄(3~5월), 가을(9~11월) 최성수기
바이럴 계수매우 높음 — 초대장 자체가 공유 행위
핵심 인사이트: 초대장은 만든 사람이 직접 수십~수백 명에게 공유하므로, 한 건의 생성이 수백 건의 서비스 노출로 이어짐. "Powered by Linkmap" 푸터가 자연스러운 마케팅 채널이 됨.

3. 모듈 구성

모듈타입설명주요 필드
Hero (초대 메인) 필수 초대장의 메인 비주얼과 제목 eventType (wedding/birthday/baby/gathering/custom)
title, subtitle
heroImageUrl
gradientFrom, gradientTo
DDay (카운트다운) 필수 D-Day 플립 카운트다운 + 일시 표시 eventDate (ISO 8601)
eventTime
showCountdown (boolean)
countdownStyle (flip/simple)
Hosts (주인공 소개) 선택 결혼 커플 또는 행사 주인공 정보 hosts[]: name, role, avatarUrl, phone
couplePhoto (웨딩용)
Location (장소 안내) 선택 장소, 지도 연동, 교통 정보 venueName, venueAddress
kakaoMapUrl, naverMapUrl
parkingInfo, transitInfo
Gallery (포토) 선택 사진 갤러리 (웨딩 촬영, 성장 앨범 등) images[], columns (2/3/4)
autoSlide (boolean)
GuestBook (축의금) 선택 계좌번호 복사 + 카카오페이 연동 bankAccounts[]: bankName, accountNumber, holder
kakaoPayUrl
RSVP (참석 확인) 선택 참석 여부 확인 폼 rsvpEnabled, rsvpFormUrl
rsvpDeadline, mealChoice
Contact (연락처) 선택 신랑/신부 측 연락처 contacts[]: name, phone, role

6. 차별화 포인트

  • D-Day 플립 카운트다운 — 기존 공유 CountUp 컴포넌트 변형 활용
  • 카카오맵/네이버맵 원탭 길찾기 — 모바일 딥링크 연동
  • 계좌번호 클립보드 복사 — 한 탭으로 복사 완료
  • 카카오페이 직접 연동 — QR 없이 URL로 송금
  • 카카오톡 공유 최적화 — OG 메타태그 + 썸네일 자동 생성
  • 이벤트 타입별 UI 분기 — 결혼/돌잔치/생일/모임 각각 최적화된 레이아웃
  • 기존 event-page와 차별 — event-page는 컨퍼런스/밋업용(스피커, 타임테이블). invitation은 개인 경조사 특화
