3. 모듈 구성

모듈타입설명주요 필드
Hero (강의 메인) 필수 강의 제목, 썸네일, CTA 버튼, 가격 title, subtitle
heroImageUrl (썸네일)
ctaText ("수강 신청")
ctaUrl, price
originalPrice (할인 표시)
badge ("인기"/"신규"/"마감임박")
Instructor (강사) 필수 강사 프로필, 경력, 자격 name, avatarUrl, bio
credentials[], socials[]
Curriculum (커리큘럼) 선택 섹션별 강의 목록 (아코디언) sections[]: title, lessons[]{title, duration, isFree?}
totalDuration, totalLessons (자동 합산)
Benefits (추천 대상) 선택 "이런 분께 추천" + 기대 효과 targetAudience[], outcomes[]
Reviews (수강 후기) 선택 별점 + 텍스트 후기 reviews[]: name, rating(1-5), text, date
averageRating (자동 계산)
FAQ (자주 묻는 질문) 선택 아코디언 형태 FAQ faq[]: question, answer
PricingCTA (가격표) 선택 플랜 비교 + CTA plans[]: name, price, features[], ctaUrl, recommended?
earlyBirdDeadline
Contact (문의) 선택 이메일, 카카오 채널, 오픈채팅 email, kakaoChannel, openChatUrl

6. 차별화 포인트

  • 가격 할인 자동 계산 — originalPrice / price 비교로 할인율 자동 표시
  • 별점 평균 자동 계산 — reviews 배열에서 자동 산출 + 별 아이콘 렌더링
  • 커리큘럼 아코디언 — 총 시간/총 강의 수 자동 합산
  • 얼리버드 카운트다운 — CountUp 컴포넌트 변형 (마감 긴급성)
  • Sticky CTA — 스크롤 시 하단 고정 수강 신청 버튼
  • 플랫폼 독립 — 클래스101/탈잉 종속 탈피, SNS 광고 직접 연결
