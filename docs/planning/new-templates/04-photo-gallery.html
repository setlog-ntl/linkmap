6. 차별화 포인트

  • Masonry 레이아웃 — Pinterest 스타일, 이미지 원본 비율 유지
  • 라이트박스 풀스크린 뷰어 — 클릭 시 전체화면, 좌우 스와이프/키보드 네비게이션
  • 컬렉션(앨범) 분류 — 카테고리 필터 탭으로 포트폴리오 구조화
  • 이미지 Lazy Loading — Blur Placeholder로 쾌적한 로딩 경험
  • 가로 스크롤 모드 — 히어로 영역에서 시네마틱 프레젠테이션
  • EXIF 정보 표시 — 라이트박스에서 카메라/렌즈/설정값 표시 (선택)
  • 촬영 패키지 모듈 — 웨딩 스냅, 프로필 촬영 등 직접 예약 유도
구현 난이도 참고: Masonry + Lightbox는 CSS columns + JS 이벤트 핸들러로 정적 사이트에서도 구현 가능. 외부 라이브러리 없이 바닐라 JS로 작성하여 번들 사이즈 최소화.
