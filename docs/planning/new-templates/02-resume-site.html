1. 타겟 사용자 & 시나리오

1차 타겟

취업 준비생, 이직 희망자, 경력직 전환자 (모든 직군 — 개발자뿐 아니라 디자이너, 마케터, 기획자)

2차 타겟

바이브코더가 본인 이력서를 웹사이트로 만들고 싶은 경우, 프리랜서 첫 이력서

사용 시나리오

"노션 이력서 대신 내 도메인에 올릴 수 있는 이력서 사이트가 갖고 싶어요"
"면접 전에 URL 하나 보내면 모든 경력이 한눈에 보이게 하고 싶어요"
"개발자가 아니라 dev-showcase는 맞지 않고, 범용 이력서가 필요해요"

3. 모듈 구성

모듈타입설명주요 필드
Hero (프로필 헤더) 필수 이름, 직함, 프로필 사진, 연락처 name, title (직함/목표직무)
avatarUrl, email, phone
linkedinUrl, githubUrl
tagline (한줄 소개)
About (자기소개) 선택 자유 형식 자기소개 about, aboutEn
Experience (경력) 선택 경력 타임라인 experience[]: company, position, period, description, highlights[]
Education (학력) 선택 학력 정보 education[]: school, degree, major, period
Skills (기술/역량) 선택 스킬 시각화 (3가지 차트 스타일) skills[]: category, items[]{name, level(1-5)}
chartType (bar/radar/tag)
Projects (프로젝트) 선택 주요 프로젝트/성과 projects[]: title, description, techStack[], link, period
Certifications (자격증) 선택 자격증/수상 이력 certifications[]: name, issuer, date, credentialUrl
PDFDownload (이력서 다운로드) 선택 PDF 이력서 CTA 버튼 resumeUrl, ctaText
Contact 선택 기존 공유 모듈 재사용 email, phone, socials[]

6. 차별화 포인트

  • 범용성 — dev-showcase가 개발자 전용이라면, resume-site는 모든 직군
  • 스킬 시각화 3가지 — Bar Chart / Radar Chart / Tag Cloud 중 선택
  • 경력 타임라인 — AnimatedReveal 활용 인터랙티브 스크롤
  • PDF 다운로드 CTA — 상단 고정 버튼으로 전환율 극대화
  • 프린트 최적화 — @media print CSS로 깔끔한 인쇄
  • SEO 최적화 — "이름 + 직함" 검색 시 상위 노출
