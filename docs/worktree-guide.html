Git Worktree Claude Code Linkmap 프로젝트

동시 작업 충돌 없이
Worktree × Claude Code 가이드

여러 기능을 동시에 개발할 때 파일 충돌 없이 안전하게 작업하는 방법. Git Worktree를 이용해 각 작업에 독립된 폴더를 만들고, Claude Code로 병렬 개발합니다.

1. Worktree가 뭔가요? (1분 요약)

아파트 비유로 이해하세요.

🏠
기존 방식 (브랜치만)

방 하나에 짐이 섞여있음. 기능A 작업하다가 기능B 파일 건드리면 충돌 발생.

충돌 위험
🏢
Worktree 방식

기능별로 방이 따로 있음. 각 방(폴더)에서 독립 작업. Git 이력은 공유.

완전 격리
🔗
공통점

같은 Git 저장소(.git)를 공유. 작업 완료 후 main에 머지. 브랜치 기록 유지.

동일 레포
폴더 구조 비교
❌ 기존 (충돌 위험)
C:\Dev\
└── linkmap\         ← 하나의 폴더
    ├── src/         ← 모든 세션이 같이 수정
    └── .git/
✅ Worktree (격리됨)
C:\Dev\
├── linkmap\             ← main (원본)
│   └── .git/
├── linkmap-dx-score\    ← 기능A 독립 폴더
└── linkmap-compare-api\ ← 기능B 독립 폴더

2. 핵심 명령어 4개

이 4개만 알면 됩니다.

생성 
git worktree add ../linkmap-기능명 -b feat/기능명

현재 폴더 옆에 linkmap-기능명 폴더 생성 + 새 브랜치 자동 생성

목록 
git worktree list

현재 활성화된 모든 worktree와 브랜치 확인

이동 
cd ../linkmap-기능명

해당 worktree 폴더로 이동 후 Claude Code 실행

삭제 
git worktree remove ../linkmap-기능명

작업 완료 후 폴더 제거 (브랜치는 유지됨)

3. 전체 워크플로우

실제 작업 순서를 단계별로 따라하세요.

1
Worktree 생성 (main 폴더에서 실행)
# main 브랜치가 최신인지 확인
cd /c/Dev/linkmap
git checkout main && git pull

# 새 worktree 생성 (폴더명은 작업 내용으로)
git worktree add ../linkmap-dx-score -b feat/dx-score
git worktree add ../linkmap-compare-api -b feat/compare-api

→ C:\Dev\linkmap-dx-score 폴더가 자동 생성됩니다

2
각 Worktree에서 Claude Code 실행
# 터미널 1 — 기능 A 작업
cd /c/Dev/linkmap-dx-score
claude  # Claude Code 시작

# 터미널 2 — 기능 B 작업 (동시에!)
cd /c/Dev/linkmap-compare-api
claude  # Claude Code 시작
완전 독립 폴더 파일 충돌 없음 동시 실행 가능
3
각 Worktree에서 커밋 & 푸시 (/gitp)
# 각 worktree 폴더의 Claude Code에서
/gitp

# 또는 직접 명령어로
git add -p          # 변경사항 확인하며 스테이징
git commit -m "feat: dx-score 점수 계산 로직 추가"
git push -u origin feat/dx-score
4
main에 머지
# main 폴더로 이동
cd /c/Dev/linkmap
git checkout main

# 첫 번째 기능 머지
git merge feat/dx-score

# 두 번째 기능 머지 (충돌 있으면 해결 후)
git merge feat/compare-api

git push
5
Worktree 정리
# 작업 완료된 worktree 제거
git worktree remove ../linkmap-dx-score
git worktree remove ../linkmap-compare-api

# 브랜치도 삭제 (선택)
git branch -d feat/dx-score feat/compare-api

폴더만 제거됩니다. Git 이력은 main에 영구 보존.

4. 한눈에 보는 흐름도

main  ──●──────────────────────────────────────────────●── push
          │                                              ▲
          │  git worktree add                            │ merge
          ├──→ linkmap-dx-score/   [브랜치: feat/dx-score]
          │      Claude 작업 → /gitp ──────────────────→ ┘
          │
          └──→ linkmap-compare-api/ [브랜치: feat/compare-api]
                 Claude 작업 → /gitp ──────────────────→ ┘

각 폴더는 완전히 독립 — 파일 충돌 없음, 동시 작업 가능
