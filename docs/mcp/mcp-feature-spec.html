Overview

기능 개요

MCP(Model Context Protocol)는 AI 코딩 도구가 외부 서비스에 접근하기 위한 표준 프로토콜입니다. Linkmap의 MCP 연결 관리 기능은 사용자가 프로젝트에서 사용하는 MCP 서버를 통합 관리하고, 기존 서비스 의존성과 함께 시각화할 수 있게 합니다.

MCP 서버 카탈로그

Supabase, GitHub, Cloudflare 등 18개 공식/커뮤니티 MCP 서버를 사전 등록. 원클릭 추가 및 설정 위저드 제공.

Import / Export

mcp.json, claude_desktop_config.json, .cursor/mcp.json 포맷 자동 감지. 붙여넣기 또는 파일 업로드로 가져오기.

서비스 연결 자동 추천

프로젝트에 추가된 서비스를 분석하여 관련 MCP 서버를 자동 추천. 스코어링 알고리즘 기반.

Architecture

핵심 설계: MCP = 서비스와 별개의 1급 엔티티

MCP 서버는 기존 서비스(Supabase, Stripe 등)와 별도로 관리됩니다. MCP는 "AI 도구 → 서비스" 브릿지 역할이므로 서비스와 다른 라이프사이클을 가집니다.

■ mcp_servers
PK id UUID
name, slug (UNIQUE)
provider, transport
npm_package, command
default_args TEXT[]
required_env_vars JSONB
related_service_ids UUID[]
tags, difficulty_level
popularity_score, is_official
■ project_mcp_configs
PK id UUID
FK project_id → projects
FK mcp_server_id → mcp_servers
custom_name, transport
command, args, url
enabled, environment
metadata JSONB, notes
FK created_by → auth.users
deleted_at (soft delete)
■ mcp_config_env_vars
PK id UUID
FK mcp_config_id
key_name TEXT
encrypted_value (AES-256-GCM)
is_secret BOOLEAN
FK source_env_var_id (optional)
■ mcp_service_links
PK id UUID
FK mcp_config_id
FK service_id → services
link_type CHECK
UNIQUE(config, service)

Security

보안 설계

RLS 정책

모든 테이블에 Row Level Security 적용. 카탈로그는 인증 사용자 전체 읽기, 프로젝트 데이터는 소유자/팀원만 접근. 관리자만 카탈로그 수정 가능.

환경변수 암호화

AES-256-GCM 대칭 암호화로 MCP 환경변수 저장. 기존 crypto 모듈 재사용. Export 시 값 미포함 (기본).

감사 로그

MCP 설정 생성/수정/삭제, 환경변수 생성 시 logAudit() 호출. mcp_config.create, .update, .delete, mcp_env_var.create 4개 액션.
