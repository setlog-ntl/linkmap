# 내가 만든 파일을 인터넷에 공개하기

AI가 만들어준 홈페이지 파일을 누구나 볼 수 있는 주소로 만드는 방법입니다.
코딩을 해본 적 없어도 괜찮습니다. 실제로 눌러야 할 버튼과 그때 보이는 화면을 순서대로 담았습니다.

---

## 시작하기 전에

### 이 문서가 해결해주는 문제

ChatGPT나 Claude에게 "카페 홍보 페이지 만들어줘"라고 하면 HTML 파일을 만들어 줍니다.
그런데 그 파일을 더블클릭하면 **내 컴퓨터에서만** 열립니다.
친구에게 보여주려면 파일을 통째로 보내야 하고, 손님에게 보여줄 주소는 없습니다.

이 문서는 그 파일을 **`https://...`로 시작하는 진짜 주소**로 만드는 방법을 다룹니다.
주소가 생기면 카카오톡으로 보낼 수도, 명함에 적을 수도, 검색되게 할 수도 있습니다.

### 준비물 두 가지

| 준비물 | 설명 |
|---|---|
| **AI가 만들어준 파일** | HTML 파일 하나여도 되고, 여러 파일이 든 ZIP(압축 파일)이어도 됩니다 |
| **GitHub 계정** | 파일이 보관될 창고입니다. 무료이고, Linkmap 로그인 과정에서 바로 만들 수 있습니다 |

> **GitHub이 뭔가요?**
> 전 세계 개발자들이 코드를 보관하는 창고입니다. 여러분의 홈페이지 파일도 여기에 보관되고,
> GitHub이 그 파일을 인터넷에 무료로 공개해 줍니다. 서버를 빌리거나 매달 돈을 낼 필요가 없습니다.

### 얼마나 걸리나요

처음 한 번은 **5분에서 10분** 정도 걸립니다.
그중 대부분은 컴퓨터가 알아서 하는 시간이라 기다리기만 하면 됩니다.
두 번째부터는 2~3분이면 끝납니다.

## 1단계 — 로그인

![로그인 화면](images/01-login.jpg)

`linkmap.biz`에 접속하면 로그인 화면이 나옵니다.
**Google** 또는 **GitHub** 버튼을 누르는 것이 가장 빠릅니다. 비밀번호를 새로 만들 필요가 없습니다.

> **어느 것을 고를까요?**
> GitHub 계정이 이미 있다면 **GitHub**을 누르세요. 나중에 필요한 연결이 한 번에 끝납니다.
> 없다면 **Google**로 시작해도 됩니다. GitHub 계정은 배포할 때 만들어도 늦지 않습니다.

---

## 2단계 — 시작 화면 이해하기

로그인하면 **원클릭 배포** 화면이 나옵니다.

![시작 화면](images/02-start.jpg)

화면 위쪽에 **1 선택 → 2 생성 → 3 완료** 세 단계가 보입니다. 지금은 1번 자리입니다.

여기서 길이 두 갈래로 나뉩니다.

| 카드 | 이럴 때 고르세요 |
|---|---|
| **내 파일 올리기** | AI가 만들어준 HTML·ZIP 파일이 **컴퓨터에 있을 때** |
| **내 GitHub 가져오기** | 파일이 이미 **GitHub 저장소에 올라가 있을 때** |

아래로 내리면 미리 만들어진 템플릿(디자인 견본)도 고를 수 있지만,
이 문서는 **내가 만든 파일**을 올리는 방법을 다룹니다.

화면 중간의 초록색 줄에 `@내계정 연결됨`이라고 보이면 GitHub 연결이 끝난 상태입니다.
연결되어 있지 않으면 카드를 눌렀을 때 연결하라는 안내가 나옵니다. 안내를 따라 한 번만 하면 됩니다.

---

## 3단계 — 파일 올리기

**내 파일 올리기** 카드를 누르면 이 화면이 나옵니다.

![업로드 화면](images/03-upload-empty.jpg)

가운데 점선 상자에 **파일을 끌어다 놓으면** 됩니다.
끌어다 놓기가 어려우면 아래 두 버튼을 쓰세요.

- **파일 고르기** — HTML 파일 하나, 또는 ZIP 압축 파일
- **폴더 고르기** — 여러 파일이 든 폴더를 통째로

> **어떤 형태로 올려야 하나요?**
> 셋 다 됩니다. AI가 파일 하나만 줬으면 그것만 올리면 되고,
> 이미지·CSS가 함께 있으면 폴더째 압축해서 올리면 됩니다.
> **폴더를 한 번 감싸서 압축해도 알아서 풀어줍니다.** 신경 쓰지 않아도 됩니다.

---

## 4단계 — 무엇이 올라가는지 확인하기 ⭐

파일을 올리면 **올릴 파일 목록**이 나타납니다. 이 화면을 꼭 확인하세요.

![파일 요약](images/04-file-summary.jpg)

이 화면이 알려주는 것이 세 가지입니다.

**① 실제로 올라갈 파일**
`index.html`, `style.css` 두 개가 올라갑니다.
압축 파일 안에서는 `my-cafe/` 폴더에 들어 있었는데, **폴더가 자동으로 벗겨졌습니다.**

**② 첫 화면이 무엇인지**
`index.html` 옆에 **첫 화면**이라고 표시됩니다.
방문자가 주소로 들어왔을 때 가장 먼저 보게 될 페이지라는 뜻입니다.

> **`index.html`이 없으면 어떻게 되나요?**
> 파일이 하나뿐이면 이름이 무엇이든 알아서 첫 화면으로 만들어 줍니다.
> HTML 파일이 여러 개인데 `index.html`이 없으면 **"첫 화면으로 보여줄 파일을 골라주세요"** 라고 물어봅니다.
> 고르기 전까지는 배포 버튼이 눌리지 않습니다.

**③ 제외된 파일과 그 이유** — 가장 중요합니다

> 다음 1개는 배포에서 제외돼요
> `.env` — 숨김 파일은 배포에 포함되지 않아요

`.env`는 비밀번호나 열쇠 같은 걸 적어두는 파일입니다.
실습용 압축 파일에는 일부러 이 파일을 넣어 두었습니다.

**이런 파일이 인터넷에 공개되면 큰 사고입니다.** 누구나 볼 수 있게 되니까요.
그래서 이름이 점(`.`)으로 시작하는 파일은 **자동으로 빠집니다.**

무엇이 빠졌는지 **배포하기 전에** 이렇게 보여주므로,
"내가 올린 파일이 왜 안 보이지?" 하고 헤맬 일이 없습니다.

## 5단계 — 주소 정하기

![주소 입력](images/05-site-address.jpg)

**사이트 주소** 칸에 원하는 이름을 적습니다. 여기서는 `cafe-haru`라고 적었습니다.

적자마자 아래에 **실제 주소가 미리 보입니다.**

```
https://내계정.github.io/cafe-haru
```

이것이 앞으로 사람들에게 알려줄 주소입니다.

**주소 짓는 규칙**

| 규칙 | 예 |
|---|---|
| 영문 소문자·숫자·하이픈(-)만 | `cafe-haru` ✅ |
| 한글·공백·대문자는 안 됩니다 | `카페하루`, `Cafe Haru` ❌ |
| 이미 쓴 이름이면 알려줍니다 | 다른 이름을 적으면 됩니다 |

> **나중에 바꿀 수 있나요?**
> 주소는 배포 후에도 바꿀 수 있지만, 이미 알려준 주소는 더 이상 열리지 않습니다.
> 처음에 신중히 정하는 편이 좋습니다.

## 6단계 — 배포하고 기다리기

**내 사이트 만들기** 버튼을 누르면 2단계 **생성**으로 넘어갑니다.

![배포 진행 중](images/06-deploying.jpg)

세 개의 작은 단계가 차례로 진행됩니다.

| 단계 | 이때 일어나는 일 |
|---|---|
| **준비 중** | GitHub에 파일 보관함(저장소)을 만들고 파일을 올립니다 |
| **설정 중** | GitHub에게 "이 파일들을 인터넷에 공개해줘"라고 설정합니다 |
| **게시 완료** | 전 세계에서 접속할 수 있게 됩니다 |

> ⏱ **여기서 2~4분 걸립니다. 정상입니다.**
> 화면이 멈춘 것처럼 보여도 기다리세요. 경과 시간이 올라가고 있으면 진행 중입니다.
> 다른 탭을 봐도 괜찮습니다 — 돌아오면 진행 상황이 이어져 있습니다.
> 다만 **이 페이지를 닫지는 마세요.**

## 7단계 — 완성 확인

![완료 화면](images/07-done.jpg)

**사이트가 준비되었습니다!** 와 함께 내 사이트 화면이 미리보기로 나옵니다.
주소를 누르면 실제 사이트가 열립니다.

아래 네 개의 버튼이 있습니다.

| 버튼 | 하는 일 |
|---|---|
| **사이트 방문** | 실제 사이트를 새 탭에서 엽니다 |
| **사이트 편집** | 글자나 색을 바로 고칠 수 있습니다 |
| **GitHub 레포** | 파일이 보관된 창고를 봅니다 |
| **대시보드** | 사이트 관리 화면으로 갑니다 |

## 8단계 — 진짜 인터넷에 올라갔는지 확인

주소를 눌러 보면 이렇게 보입니다.

![공개된 사이트](images/08-live-site.jpg)

이 주소는 이제 **누구나** 접속할 수 있습니다.
휴대폰으로 열어보거나, 카카오톡으로 자신에게 보내서 확인해 보세요.

> **친구에게 보여주려면?**
> 주소를 그대로 복사해서 보내면 됩니다. 앱을 깔거나 로그인할 필요가 없습니다.

## 9단계 — 내가 만든 사이트 관리하기

위쪽 **내 사이트** 탭을 누르면 지금까지 만든 사이트가 모두 보입니다.

![내 사이트 목록](images/09-my-sites.jpg)

사이트 이름 아래에 **출처**가 적혀 있습니다.

| 표시 | 뜻 |
|---|---|
| **내가 올린 파일** | 파일을 직접 올려서 만든 사이트 |
| **템플릿: ○○** | 미리 만들어진 디자인으로 만든 사이트 |
| **내 GitHub 저장소** | 원래 있던 저장소를 연결한 사이트 |

각 사이트마다 쓸 수 있는 버튼이 다릅니다.
**내 GitHub 저장소**로 만든 사이트에는 **편집 버튼이 없습니다.**
원래 여러분의 저장소이므로, Linkmap이 함부로 고치지 않기 위해서입니다.

### 이 사이트가 쓰는 서비스

사이트에 Google Analytics(방문자 통계)나 결제 기능 같은 걸 넣었다면,
Linkmap이 그걸 알아보고 **"이 사이트가 쓰는 서비스"** 로 알려줍니다.

**서비스맵에 담기**를 누르면 그 서비스들이 관리 화면에 정리됩니다.
어떤 열쇠(API 키)가 필요한지, 잘 작동하는지 한곳에서 볼 수 있게 됩니다.

> 자동으로 담지는 않습니다. 추측이 틀릴 수도 있으니 **여러분이 확인하고 고르는 방식**입니다.

## 또 다른 방법 — 내 GitHub 저장소 가져오기

파일이 이미 GitHub에 올라가 있다면 올릴 필요 없이 **연결만** 하면 됩니다.

### 저장소 고르기

**내 GitHub 가져오기** 카드를 누르면 내 저장소 목록이 나옵니다.

![저장소 목록](images/10-repo-list.jpg)

저장소가 많으면 위쪽 검색창에 이름 일부를 적어 찾으세요.

### 무엇이 추가되는지 확인하기 ⭐

저장소를 고르면 **동의 화면**이 나옵니다. 이 화면이 이 방법의 핵심입니다.

![동의 화면](images/11-consent.jpg)

여기서 세 가지를 약속합니다.

**① 딱 1개의 파일만 추가합니다**
`.github/workflows/linkmap-pages.yml` 하나입니다.
GitHub에게 "이 저장소를 인터넷에 공개해줘"라고 알려주는 설명서 파일입니다.

**② 기존 파일은 수정하지 않습니다**
여러분이 만든 파일은 글자 하나 건드리지 않습니다.

**③ 저장소를 삭제하지 않습니다**
나중에 Linkmap에서 이 사이트를 지워도 **GitHub 저장소는 그대로 남습니다.**

### 추가될 내용 직접 보기

파일 이름 옆의 화살표를 누르면 **커밋될 내용 전문**이 그대로 펼쳐집니다.

![워크플로우 전문](images/12-consent-yaml.jpg)

무슨 뜻인지 몰라도 괜찮습니다.
중요한 건 **"뭘 넣는지 숨기지 않는다"** 는 점입니다. 확인하고 싶으면 언제든 볼 수 있습니다.

마지막으로 **1개 파일 커밋하고 배포** 버튼을 누르면 끝입니다.

> **빌드가 필요한 프로젝트라면?**
> React나 Vite로 만든 프로젝트는 "재료를 조립해야" 완성됩니다.
> 이때는 화면에 **"Vite 프로젝트로 보여요 — GitHub에서 빌드한 뒤 게시합니다"** 라고 표시되고,
> 조립까지 알아서 해줍니다. 여러분이 할 일은 똑같이 버튼 하나입니다.

## 자주 막히는 곳

### "GitHub 계정이 연결되어 있지 않습니다"

**내 파일 올리기**를 누르기 전에 GitHub 연결이 필요합니다.
화면 안내를 따라 GitHub에 로그인하고 권한을 허용하면 한 번만 하면 끝입니다.

### 올린 파일 중 일부가 목록에 없어요

일부러 뺀 것입니다. 4단계의 **"배포에서 제외돼요"** 목록을 확인하세요. 주로 이런 것들입니다.

| 빠지는 것 | 이유 |
|---|---|
| 점(`.`)으로 시작하는 파일 | 비밀 정보가 들어 있을 수 있어서 |
| `.exe`, `.sh` 같은 실행 파일 | 홈페이지에서 쓸 수 없어서 |
| 너무 큰 파일 | 사진은 2MB 정도로 줄여서 올리세요 |

### "index.html이 없습니다"

첫 화면이 될 파일이 없다는 뜻입니다.
HTML 파일이 하나도 없으면 AI에게 **"HTML 파일로 저장해줘"** 라고 다시 요청하세요.

### 배포는 됐는데 화면이 깨져 보여요

이미지나 디자인 파일 경로가 어긋난 경우입니다.
AI에게 이렇게 요청해 보세요.

> "이미지 경로를 `/images/logo.png` 같은 절대경로 말고 `images/logo.png` 같은 상대경로로 바꿔줘"

### "로그인이 풀렸습니다"

시간이 지나면 로그인이 만료됩니다.
페이지를 새로고침하고 다시 로그인한 뒤, **파일을 다시 골라서** 배포하세요.

### 배포가 계속 "설정 중"에서 안 넘어가요

먼저 **3~5분** 기다려 보세요. 처음 배포는 원래 오래 걸립니다.
그래도 안 되면 **내 사이트** 탭에서 상태를 확인하고, 오류로 표시되면 **재배포**를 눌러보세요.
