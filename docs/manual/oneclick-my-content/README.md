## 독자가 배우는 것

코딩을 해본 적 없는 사람이 **AI에게 받은 HTML 파일을 인터넷에 공개**하기까지의 전 과정입니다.
실습은 "카페 사장님이 AI에게 받은 홍보 페이지를 올린다"는 하나의 시나리오로 이어집니다.

실습용 ZIP에는 의도적으로 두 가지 장치를 넣었습니다.

| 넣어둔 것 | 매뉴얼에서 가르치는 것 |
|---|---|
| `my-cafe/` 폴더로 한 번 감싼 구조 | 폴더째 압축해도 알아서 풀린다 |
| `.env` (비밀번호가 든 파일) | 비밀 정보는 **자동으로 빠진다** — 안전장치를 눈으로 확인 |

## 화면 캡처 다시 찍는 방법

화면이 바뀌면 캡처를 다시 떠야 합니다. 다음 조건을 맞춰 주세요.

- 브라우저 창 너비 **1017px 이상** (좌측 사이드바가 함께 보여야 합니다)
- 캡처 전 **개인정보 가리기** — 이메일과 이름은 화면에 그대로 나오므로 반드시 가립니다.
  콘솔에 아래를 붙여넣으면 자동으로 가려집니다.

```js
function mask() {
  document.querySelectorAll('*').forEach(el => {
    if (el.children.length === 0 && el.textContent) {
      if (el.textContent.includes('내이메일@주소')) el.textContent = 'hello@example.com';
      if (el.textContent.trim() === '내이름') el.textContent = '홍길동';
    }
  });
}
mask();
new MutationObserver(mask).observe(document.body, { childList: true, subtree: true });
```

- 파일명은 `NN-화면이름.jpg` 형식으로 순서를 유지합니다 (`01-login.jpg`, `02-start.jpg` …)

## 영상 제작 시 참고

매뉴얼의 각 단계가 영상 한 장면에 대응하도록 썼습니다.
"이때 화면에는 이렇게 보입니다"라고 적힌 문장이 곧 캡처 시점입니다.

배포에는 실제로 **2~4분**이 걸립니다. 영상에서는 이 구간을 편집으로 줄이되,
"실제로는 몇 분 걸린다"는 안내를 넣어야 시청자가 자기 화면이 멈춘 줄 알고 이탈하지 않습니다.
